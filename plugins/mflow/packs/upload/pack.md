แพ็กนี้คือกติกากลางของไฟล์แนบในทุกระบบ: รับไฟล์ชนิดไหน ใหญ่ได้แค่ไหน ตรวจเนื้อไฟล์อย่างไร เก็บที่ไหนในชื่ออะไร ผูกกับรายการเมื่อไร ใครดาวน์โหลดได้ เอาออกแล้วเป็นอย่างไร และอะไรลง Activity Log ไฟล์ทุกไฟล์เป็นของ `{record}` หนึ่งรายการ และเข้าถึงได้ผ่านรายการนั้นเท่านั้น

## ครอบคลุม

- ชุดชนิดไฟล์ที่ระบบตรวจเนื้อไฟล์ได้ และรายการชนิดที่รับจริงบนหน้าตั้งค่าระบบ
- ขนาดต่อไฟล์ จำนวนและขนาดรวมต่อรายการ เพดานขนาดคำขอของ server
- การตรวจก่อนรับ: นามสกุล เนื้อไฟล์ตรงกับนามสกุล ไฟล์ว่าง และชื่อไฟล์ที่ล้างแล้ว
- ที่เก็บไฟล์หลัง interface เดียว (object storage หรือ volume นอก web root) และ key ที่ไม่มีข้อความจากผู้ใช้
- อัปโหลดเข้าที่พักก่อน แล้วผูกกับ `{record}` ตอนบันทึกฟอร์ม และการล้างไฟล์ที่ค้างในที่พัก
- ดาวน์โหลดผ่าน API หลังตรวจสิทธิ์ดูรายการ พร้อม header ที่กันการเปิดไฟล์ในหน้าเว็บ
- เอาไฟล์ออกและแทนที่ตามกติกาของรายการ และอายุของไฟล์ที่เอาออกแล้ว
- checksum (sha256) การสแกนไวรัสเมื่อมีผู้ใช้ภายนอก และจำนวนอัปโหลดต่อชั่วโมงบน `{org_portal}`
- Activity Log ของการแนบและการเอาออก
- ช่องแนบไฟล์ รายการไฟล์บนหน้ารายละเอียด และค่าในแท็บ Upload ของหน้าตั้งค่าระบบ

## ไม่รวม

- หน้าตั้งค่าระบบ การเก็บค่า และกติกาการแก้ค่า: อยู่ในแพ็ก `settings` แพ็กนี้บอกแค่ว่ามีค่าอะไร ค่าเริ่มต้น และช่วง
- ใครแก้หรือดู `{record}` ได้ และขอบเขตข้อมูล: อยู่ในแพ็ก `permission` และกติกาของรายการนั้น ไฟล์ใช้กติกาเดียวกับรายการ
- การแสดงไฟล์ในหน้าเว็บ (เปิด PDF หรือรูปแบบ inline, รูปย่อ, รูปในเนื้อหา เช่นรูปข่าว): ยังไม่อยู่ในแพ็กรุ่นนี้ ดู UPL-D11
- การส่งไฟล์ต่อไประบบเก็บเอกสารภายนอก และการดึงไฟล์จากระบบอื่น: เป็นเรื่องการเชื่อมระบบของโปรเจกต์
- การนำเข้าข้อมูลจากไฟล์ (Excel, CSV): ไฟล์ขึ้นมาตามแพ็กนี้ แต่การอ่านและตรวจข้อมูลเป็นอีกเรื่อง
- การเข้ารหัสไฟล์ที่เก็บ การสำรองข้อมูล และ lifecycle ของ bucket: เป็นงานของระบบที่ deploy
- รุ่นของไฟล์ ไฟล์บีบอัด และไฟล์ใหญ่กว่า 100 MB: ไม่มีในรุ่นนี้ ดู UPL-D01, UPL-D03, UPL-D12

## คำของโปรเจกต์

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{record}` | ชนิดรายการที่มีไฟล์แนบ แต่ละชนิดมีตารางผูกของตัวเอง | `Order`, `Contract`, `Claim` |
| `{portal}` | พอร์ทัลหรือเว็บที่ผู้ใช้อัปโหลด ระบบที่มีพอร์ทัลเดียวใช้ชื่อเดียว | back office |
| `{org_portal}` | พอร์ทัลที่คนนอกองค์กรเข้าใช้ ระบบที่มีแต่พนักงานไม่มีคำนี้ | พอร์ทัลลูกค้า, พอร์ทัลคู่ค้า |
| `{api_prefix}` | ส่วนหน้าของ route API | `/api/v1` |

ถ้าระบบไม่มี `{org_portal}` ข้ามจำนวนอัปโหลดต่อชั่วโมง (UPL-D16) และสแกนไวรัสเฉพาะเมื่อลูกค้ากำหนด (UPL-D15)
