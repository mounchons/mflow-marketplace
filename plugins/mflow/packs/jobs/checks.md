# jobs checks

สิ่งที่ลองตอนทดสอบใช้งาน แต่ละข้อเป็น test หรือ acceptance criterion ได้

1. สั่งงานหนักจากหน้าจอ เช่น export: ได้คำตอบ 202 พร้อมรหัสรอบทันที และเห็นรอบเป็น Queued แล้ว Running แล้ว Succeeded บนจองาน
2. ทำให้การบันทึกที่เข้าคิวงานล้มกลางทาง: ไม่มีแถว `job_run` ค้างและไม่มีงานเกิดขึ้น
3. เปิด API สอง container เวลาเดียวกัน แล้วรอให้รอบเวลาหนึ่งถึง: เกิดรอบเดียว และงานทำครั้งเดียว
4. กดสั่งรันงานที่กำลังรันอยู่: ได้ 409 `JOB_RUNNING` ไม่มีแถวใหม่และไม่มีรายการ `ManualTrigger`
5. ตั้งรอบงานตีสองแล้วดูจอและเวลาที่เริ่มจริง: เริ่มตีสองตามเขตเวลาของระบบ ไม่ใช่ตีสองของ UTC
6. แก้รอบงานบนจอเป็นทุก 15 นาที: รอบถัดไปเปลี่ยนทันทีโดยไม่ restart และ Activity Log มี `SaveSchedule` หนึ่งรายการพร้อมค่าเก่าและค่าใหม่
7. ปิดงานด้วยสวิตช์: ไม่มีรอบใหม่ตามเวลา รอบที่กำลังรันจบตามปกติ และยังกดสั่งรันด้วยมือได้
8. ทำให้งานครั้งเดียวล้มด้วยระบบอื่นไม่ตอบ: ลองใหม่ตามระยะห่างใน params ครบแล้วเป็น Failed พร้อมข้อความ และกดลองใหม่บนจอได้เป็นรอบใหม่
9. ทำให้งานครั้งเดียวล้มด้วยข้อมูลผิด: เป็น Failed ทันทีโดยไม่ลองใหม่
10. งานหลายรายการที่มีหนึ่งรายการพัง: รายการอื่นสำเร็จ รอบจบ Failed พร้อมจำนวนสำเร็จและล้ม และรันซ้ำแล้วไม่ทำรายการที่สำเร็จซ้ำ
11. kill process ระหว่างงานรัน: รอบถูกปิดเป็น Interrupted หลังหมดอายุ lease งานครั้งเดียวกลับเข้าคิว และรอบของเครื่องอื่นที่ยังทำงานไม่ถูกปิด
12. สั่งหยุด container ตอนงานรัน: งานหยุดหลังจบรายการปัจจุบัน รอบเป็น Interrupted และจองานไม่นับเป็นงานล้ม
13. ทำให้งานล้มติดกันครบจำนวน: มีอีเมลเตือนฉบับเดียวและแถบเตือนบนจอ ล้มต่ออีกไม่มีอีเมลเพิ่ม สำเร็จแล้วแถบหาย
14. ทำให้ error มี connection string หรือรหัสผ่าน: จองานและ `job_run.error_text` ไม่มีค่านั้น stack trace อยู่ใน log พร้อมรหัสรอบ
15. ผู้ไม่มี `{job_view_key}` เข้าจองานตรงๆ: ไม่มีเมนู ขึ้นหน้าไม่มีสิทธิ์ และ API ตอบ 403 ส่วนผู้มีแค่ `{job_view_key}` ไม่เห็นปุ่มสั่งรันและแก้รอบ
16. เลื่อนนาฬิกาเกินอายุเก็บประวัติแล้วให้งานล้างรัน: แถวเก่าหาย รอบที่ยังรันอยู่ไม่ถูกลบ และ Activity Log ไม่มีรายการใหม่
17. (test) ตั้ง `jobs.mode` เป็น `Inline`: งานครั้งเดียวจบก่อนคำตอบกลับ และไม่มีรอบตามเวลาเริ่มเองระหว่าง test
18. (test) เพิ่มงานใหม่ใน catalog แล้ว start: แถวใหม่ถูกเพิ่ม รอบและสวิตช์ที่ลูกค้าตั้งไว้ของงานเดิมไม่เปลี่ยน
