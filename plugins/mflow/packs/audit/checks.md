# สิ่งที่ลองตอนทดสอบใช้งาน

1. ผู้ใช้ A สร้างเอกสาร แล้วผู้ใช้ B แก้หนึ่งฟิลด์ → ในฐานข้อมูล `created_by` เป็น A `updated_by` เป็น B และ Activity Log มีรายการ Edit ที่มีค่าเก่าและค่าใหม่ของฟิลด์นั้น
2. ลบเอกสารพร้อมเหตุผล → เอกสารหายจากรายการ แต่แถวยังอยู่พร้อม `deleted_by` และเหตุผล และสร้างเอกสารใหม่ด้วยรหัสเดิมได้
3. ปล่อยให้งานตามเวลาทำงานหนึ่งรอบ → รายการที่เกิดแสดงผู้ทำ "System · ระบบ" และบทบาท System ส่วนการกดสั่งรันด้วยมือแสดงชื่อคนที่กด
4. ผู้ใช้ที่มีแค่สิทธิ์ดู เปิด Activity Log → เห็นหมายเหตุว่าดูเฉพาะของตัวเอง เห็นแค่รายการของตัวเอง และใส่ id ของคนอื่นใน address ได้หน้าว่าง
5. เปลี่ยนรหัสผ่าน แล้วเปิดรายการนั้น → ฟิลด์รหัสผ่านขึ้นว่า Changed โดยไม่มีค่าใดๆ
6. สองคนเปิดเอกสารเดียวกัน คนแรกบันทึก แล้วคนที่สองบันทึก → คนที่สองได้ข้อความว่ามีคนแก้ไปก่อน และค่าของคนแรกยังอยู่
7. นำเข้าข้อมูลหลายร้อยแถวในครั้งเดียว → Activity Log มีหนึ่งรายการ รายละเอียดแสดงไม่เกิน 20 แถว และบอกจำนวนแถวทั้งหมด
8. ดูทุกหน้าของ Activity Log → ไม่มีปุ่มแก้ ลบ หรือ export และแท็บทั้งสี่แสดงจำนวนที่รวมกันเท่ากับแท็บ All
9. (test) ทำให้การเขียน log ล้มเหลว → งานธุรกิจไม่ถูกบันทึก
10. (test) role ของแอปสั่ง UPDATE หรือ DELETE บน `activity_log` → ฐานข้อมูลปฏิเสธ
