แพ็กนี้คือกติกากลางของการคุยกับ `{external_system}` ทุกตัว: โค้ดธุรกิจเรียกผ่าน port เท่านั้น ค่าเชื่อมต่ออยู่ที่ไหน รอได้นานแค่ไหน ลองใหม่เมื่อไรและห้ามลองเมื่อไร การเขียนหนึ่งครั้งไม่เกิดซ้ำได้อย่างไร อะไรรอในคิว อะไรลง log จอติดตาม การแจ้งเตือน ของปลอมสำหรับเครื่องพัฒนา และการรับคำขอที่อีกฝั่งยิงเข้ามา แพ็กนี้ไม่รู้จักระบบภายนอกตัวใดเป็นพิเศษ รายชื่อระบบและ `{operation}` ของแต่ละตัวเป็นของโปรเจกต์ (INTG-D02)

## ครอบคลุม

- port หนึ่งตัวต่อ `{external_system}` และตารางระบบ: ทิศทาง ตัวกระตุ้น เจ้าของข้อมูล
- ค่าเชื่อมต่อ (address ผู้ใช้ ความลับ) บนหน้าตั้งค่าระบบ และ env ที่กันเครื่องทดสอบเรียกของจริง
- เวลารอ, token, ตารางผลของรหัสตอบกลับ, การลองใหม่ และกรณีที่ห้ามลองใหม่
- การเขียนไม่ซ้ำ (idempotency) และคิวงานเขียน `integration_outbox` ที่อยู่รอดเมื่อระบบล้ม
- จุดอ่านล่าสุด (sync cursor) ของการดึงเข้า
- log ต่อการเรียก การปิดบังความลับ รหัสอ้างอิง อายุ และยอดรายชั่วโมงของการอ่านปริมาณมาก
- เมื่อระบบภายนอกล่ม: ผู้ใช้เห็นอะไร อะไรรอ และการตัดวงจร
- จอติดตาม การส่งซ้ำและดึงซ้ำด้วยมือ ใครใช้ได้ และการแจ้งเตือนเมื่อล้มซ้ำ
- ของปลอมของ `{external_system}` การทำให้ล้มเพื่อทดสอบ ปุ่มทดสอบการเชื่อมต่อ และชุดทดสอบสัญญา
- webhook ขาเข้า: ลายเซ็น การกันเล่นซ้ำ ตาราง `integration_inbox`
- รุ่นของ API อีกฝั่ง การแปลงฟิลด์ในที่เดียว ไฟล์ที่ส่งผ่านระบบภายนอก และข้อมูลส่วนบุคคลที่ออกนอกระบบ

## ไม่รวม

- รอบงาน ตารางเวลา การกันรอบซ้อน บันทึกต่อรอบ การสั่งรันด้วยมือ และการเตือนเมื่อรอบล้มติดกัน: อยู่ในแพ็ก `jobs` แพ็กนี้บอกแค่ว่าแต่ละรายการในรอบทำอะไรเมื่อล้ม
- หน้าตั้งค่าระบบ การเก็บและเข้ารหัสค่า: อยู่ในแพ็ก `settings` แพ็กนี้บอกแค่ว่ามีค่าอะไร
- ใครถือสิทธิ์ และขอบเขตข้อมูล: อยู่ในแพ็ก `permission` แพ็กนี้ใช้แค่ชื่อคีย์
- ตัวส่งอีเมลและ SMTP: อยู่ในแพ็ก `mail` ถึงแม้ SMTP เป็นระบบภายนอก แพ็กนั้นดูแลเอง
- การรับและเก็บไฟล์: อยู่ในแพ็ก `upload`
- การนำเข้าจากไฟล์ Excel หรือ CSV ที่คนอัปโหลด: อยู่ในแพ็ก `import-export`
- เส้นทางของข้อมูลธุรกิจหลังรับเข้า (สร้างเอกสาร อนุมัติ): เป็นกติกาของ `{record}` นั้น
- message broker และการแลกไฟล์ทาง SFTP: ไม่มีในรุ่นนี้ กลไกคิวและ log ใช้แนวเดียวกันได้ แต่ port ต้องเขียนเอง

## คำของโปรเจกต์

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{external_system}` | ระบบภายนอกหนึ่งตัวที่ระบบนี้คุยด้วย ใช้รหัสสั้นตัวพิมพ์เล็ก | `erp`, `accounting`, `warehouse` |
| `{operation}` | เส้นหนึ่งของ `{external_system}` ที่ระบบนี้ใช้ | `SearchOrders`, `PostInvoice`, `Token` |
| `{record}` | ชนิดรายการของระบบนี้ที่งานเขียนออกหรือการดึงเข้าผูกอยู่ | `Order`, `Invoice`, `Customer` |
| `{integration_view_key}` | สิทธิ์เปิดจอติดตามการเชื่อมต่อ | `INTEGRATION.View` |
| `{integration_manage_key}` | สิทธิ์ส่งซ้ำ ดึงซ้ำ และทดสอบการเชื่อมต่อ | `INTEGRATION.Manage` |
| `{superadmin}` | กลุ่มผู้ดูแลสูงสุดใน seed | SuperAdmin |
| `{api_prefix}` | ส่วนหน้าของ route API | `/api/v1` |
