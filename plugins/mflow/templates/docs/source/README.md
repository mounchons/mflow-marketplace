# Customer source documents

Put originals from the customer here (TOR, Word, Excel, PDF, review notes). Never edit them: a new version is a new file, for example `2026-10-tor-v2.pdf`.

Register and triage with `/mflow:capture`. `INDEX.md` is generated from `.mflow/sources.json` and shows which files are active, superseded, or reference only, and which hotspots or changes used them.
