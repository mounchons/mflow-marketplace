แพ็กนี้คือพฤติกรรมร่วมของทุกหน้าจอในเว็บ: กรอบที่ทุกหน้าอยู่ข้างใน ภาษาของป้าย วันเวลาและตัวเลข ตารางรายการ การเลือกระเบียน ประวัติในหน้ารายละเอียด ฟอร์ม ข้อความแจ้งผล หน้าข้อผิดพลาด และเซสชันที่หมดระหว่างใช้งาน แพ็กนี้ตัดสินว่าหน้าจอ "ทำอะไร" ส่วนหน้าตา (สี ตัวอักษร ระยะ ไอคอน) และ contract ของ component เป็นของ UI kit ที่ `/mflow:theme` สร้าง แพ็กนี้ไม่ซ้ำกติกาของ kit

## ครอบคลุม

- layout จาก UI kit ของโปรเจกต์ หนึ่ง layout ต่อ `{portal}` และ layout ของหน้าเข้าระบบและหน้าสาธารณะ
- sidebar กับ top bar ที่หดตามความกว้างจอ เมนูผู้ใช้ (Profile, Sign out) และชื่อหน้าบนแท็บ browser
- เมนูแสดงเฉพาะคีย์สิทธิ์ที่ผู้ใช้ถือ (คีย์มาจากแพ็ก permission)
- หน้าจอประกอบจาก component ของ kit เท่านั้น และอ่านเขียนข้อมูลผ่านชั้น server ชั้นเดียว
- ภาษาของป้าย (สองภาษาในป้ายเดียว ภาษาเดียว หรือปุ่มสลับภาษา)
- วันเวลา: เก็บ UTC แสดงตามเขตเวลาของระบบ รูปแบบวันที่และปี ค.ศ. หรือ พ.ศ. `/mflow:theme` ใช้คำตอบของแพ็กนี้เป็นรูปแบบวันที่ของ kit ไม่ถามซ้ำ
- รูปแบบตัวเลขและเงิน
- มาตรฐานตารางรายการ: ค้นหา เรียง แบ่งหน้า จำนวนแถวต่อหน้า แถวเปิดรายละเอียด สถานะว่างและกำลังโหลด และ export เฉพาะที่เรื่อง import-export กำหนด
- การเลือกระเบียนหนึ่งรายการจากรายการยาว และตารางประวัติในหน้ารายละเอียด
- ฟอร์ม: เครื่องหมายช่องบังคับ ข้อผิดพลาดข้างช่อง ข้อผิดพลาดจาก server ลงช่องที่ผิด การเตือนเมื่อออกจากหน้าที่ยังไม่บันทึก และการกดส่งซ้ำ
- ข้อความ: toast เมื่อสำเร็จ ข้อผิดพลาดแสดงในหน้า และ dialog ยืนยันก่อนทำสิ่งที่ย้อนไม่ได้โดยบอกชื่อรายการ
- หน้า 404 และ 500 เครือข่ายขาด และเซสชันหมดระหว่างใช้งาน (กลับหน้าเข้าระบบพร้อม `next`)
- หน้า style guide เฉพาะนอก production
- การเข้าถึงพื้นฐาน (ป้ายของช่อง คีย์บอร์ด focus คอนทราสต์) และ browser ที่รองรับ

## ไม่รวม

- หน้าตาและ contract ของ component, จุดตัดความกว้างจอ, เครื่องที่ใช้ทดสอบ: เป็นของ UI kit (`/mflow:theme`) ถ้าแพ็กนี้ตอบเรื่องภาษาหรือรูปแบบวันที่ต่างจากข้อความตัวอย่างใน contract ของ kit ให้ kit แสดงตามคำตอบของแพ็กนี้
- โครงเมนู ลำดับกลุ่ม หน้าแรกของแต่ละ role และการค้นหาทั้งระบบ: เรื่อง `navigation` ของโปรเจกต์
- ใครถือคีย์ไหน แผง no-access และการตรวจสิทธิ์ฝั่ง server: แพ็ก permission
- หน้าเข้าระบบ เซสชัน อายุเซสชัน และกติกาของ `next`: แพ็ก auth แพ็กนี้กำหนดแค่ว่าหน้าจอทำอะไรเมื่อเซสชันหมด
- หน้า Profile และสิ่งที่แก้ได้บนนั้น: แพ็ก users
- รูปของ error body, การแบ่งหน้าบน API และรูปวันที่บนสาย: กติกา API ของโปรเจกต์ แพ็กนี้กำหนดแค่ว่าหน้าจอแสดงอย่างไร
- ไฟล์ export, การนำเข้า และการพิมพ์: เรื่อง `import-export-print`
- หน้าต่างเตือนก่อนเซสชันหมด, โหมดมืด, ใช้งานแบบ offline, แอปมือถือ: ยังไม่อยู่ในแพ็กรุ่นนี้

## คำของโปรเจกต์

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{portal}` | เว็บหรือพอร์ทัลที่ผู้ใช้กลุ่มหนึ่งเข้า ระบบที่มีพอร์ทัลเดียวใช้ชื่อเดียว | พอร์ทัลพนักงาน, พอร์ทัลคู่ค้า |
| `{start_page}` | หน้าแรกของ `{portal}` หลังเข้าระบบ | `/`, `/dashboard` |
| `{app_name}` | ชื่อระบบที่แสดงบน sidebar และท้ายชื่อแท็บ browser ต่อ `{portal}` | Back Office |
