# auth: ค่าเริ่มต้น

ค่าที่เอกสารลูกค้ากำหนดใช้แทนค่าเริ่มต้น ทุกค่าอยู่บนหน้าตั้งค่าระบบ (แพ็ก `settings`) ปรับได้เฉพาะในช่วง ปลายช่วงคือค่าที่หลวมที่สุดที่ยอมให้ตั้ง (AUTH-D27) ค่าที่มีหมายเหตุ "ต่อพอร์ทัล" มีค่าแยกของแต่ละ `{portal}`

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| ผิดกี่ครั้งจึงล็อก | `auth.lock_failures` | 5 | 3–5 | นับต่อพอร์ทัลต่ออีเมลที่พิมพ์ รวมชื่อที่ไม่มีจริงและรหัส OTP ที่ผิด |
| หน้าต่างนับการผิด (นาที) | `auth.lock_window_minutes` | 5 | 5–60 | |
| ล็อกนาน (นาที) | `auth.lock_minutes` | 15 | 15–1440 | ข้อความล็อกบอกค่านี้ |
| ความยาวรหัสต่ำสุด | `auth.password_min_length` | 8 | 8–32 | ไม่เกินความยาวสูงสุด |
| ความยาวรหัสสูงสุด | `auth.password_max_length` | 16 | 16–64 | |
| ต้องมีอักขระพิเศษ | `auth.password_require_special` | ปิด | เปิด/ปิด | ตัวพิมพ์ใหญ่ เล็ก และตัวเลขบังคับเสมอ ไม่ใช่ค่าตั้ง |
| ห้ามซ้ำกี่รหัสล่าสุด | `auth.password_history` | 4 | 4–24 | |
| อายุรหัสผ่าน (วันปฏิทิน) | `auth.password_expiry_days` | 30 | 1–90 | เปลี่ยนแล้วคำนวณทุกบัญชีใหม่ |
| อายุลิงก์ตั้งรหัส (ชั่วโมง) | `auth.link_hours` | 24 | 1–72 | ใช้ครั้งเดียว |
| ขอลิงก์ได้กี่ครั้งต่อชั่วโมง | `auth.link_requests_per_hour` | 3 | 1–10 | ต่อบัญชี เกินแล้วตอบข้อความกลางๆ แต่ไม่ส่ง |
| อายุรหัสผ่านเริ่มต้น (ชั่วโมง) | `auth.starting_password_hours` | 24 | 1–72 | ใช้เมื่อ AUTH-D18 เป็นจริง |
| ไม่ใช้งานกี่นาทีเซสชันหมด | `auth.session_idle_minutes` | 480 | 5–480 | ต่อพอร์ทัล ไม่เกินอายุสูงสุด (AUTH-D10) |
| อายุเซสชันสูงสุด (นาที) | `auth.session_max_minutes` | 720 | 60–720 | ต่อพอร์ทัล นับจากตอนเข้า |
| อายุ access token (นาที) | `auth.access_token_minutes` | 15 | 5–15 | ต่อพอร์ทัล เฉพาะเซสชันแบบ token (AUTH-D09) ไม่เกินเวลาไม่ใช้งาน |
| เปิด OTP ทางอีเมล | `auth.otp_enabled` | ปิด | เปิด/ปิด | ต่อพอร์ทัล ปิดต้องยืนยัน env ฉุกเฉิน `AUTH_OTP_OFF` (AUTH-D24) เมื่อเอกสารลูกค้ากำหนดให้เปิด ค่าเริ่มต้นเป็นเปิดและปิดบนจอไม่ได้ |
| จำนวนหลักของรหัส OTP | `auth.otp_digits` | 6 | 6–8 | สุ่มจากแหล่งสุ่มเชิงรหัส |
| อายุรหัส OTP (นาที) | `auth.otp_code_minutes` | 5 | 1–10 | |
| อายุการรอรหัส OTP (นาที) | `auth.otp_pending_minutes` | 15 | 5–30 | นับจากผ่านรหัสผ่าน |
| รอก่อนส่งรหัสใหม่ (วินาที) | `auth.otp_resend_seconds` | 60 | 30–300 | |
| รหัส OTP สูงสุดต่อชั่วโมง | `auth.otp_codes_per_hour` | 5 | 3–10 | ต่อบัญชีต่อพอร์ทัล |
| รหัสผิดกี่ครั้งต้องเริ่มใหม่ | `auth.otp_wrong_codes` | 5 | 3–5 | ต่อการรอหนึ่งครั้ง |
| จำ browser (ชั่วโมง) | `auth.otp_remember_hours` | 24 | 0–720 | ต่อพอร์ทัล 0 = ถามทุกครั้ง |
| ลบเซสชันหลังหมดอายุ (วัน) | `auth.purge_session_days` | 1 | 1–30 | |
| ลบการเข้าผิดหลัง (วัน) | `auth.purge_attempt_days` | 1 | 1–30 | หรือนานกว่าเมื่อหน้าต่างล็อกรวมเวลาล็อกยาวกว่า |
| ลบลิงก์หลังหมดอายุ (วัน) | `auth.purge_link_days` | 30 | 1–90 | |
