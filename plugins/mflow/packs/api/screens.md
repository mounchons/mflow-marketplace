# หน้าจอของแพ็ก api

แพ็กนี้แทบไม่มีหน้าจอของตัวเอง เป็นข้อตกลงที่ทุกจอของแพ็กอื่นใช้ มีหน้าเดียวคือหน้าเอกสาร API

| หน้าจอ | ทำอะไร | ใครเข้าได้ | ส่วนสำคัญ |
|---|---|---|---|
| API docs · เอกสาร API (`<prefix>/docs`) | อ่านรายชื่อ endpoint ชนิดข้อมูล และคำตอบ error ของแต่ละ endpoint และลองเรียกได้ | ทุกคนที่เปิด Development, Prototype หรือ Staging ได้ Production ไม่มีหน้านี้ (API-D13) | อ่านจาก `<prefix>/openapi.json` ชุดเดียวกับไฟล์ contract, ลองเรียก endpoint ที่ต้องเข้าระบบด้วยเซสชันของ browser |

สิ่งที่เว็บทุกตัวต้องทำตามแพ็กนี้ แต่ไม่ใช่หน้าแยก:

- error ที่ไม่คาดคิด (500) แสดงข้อความกลางๆ พร้อม request id ให้ผู้ใช้แจ้งผู้ดูแล (API-D14)
- 409 `<RESOURCE>_CHANGED` เก็บสิ่งที่ผู้ใช้พิมพ์ไว้ และเสนอให้โหลดข้อมูลล่าสุด (API-D07)
- 400 `VALIDATION_FAILED` แสดงข้อความใต้ช่องที่ผิดทุกช่องในครั้งเดียว (API-D04)
- 429 บอกให้รอตามเวลาใน `Retry-After` และ 413 บอกว่าไฟล์หรือข้อมูลใหญ่เกิน (API-D16, API-D18)
- แบนเนอร์ prototype แสดงเมื่อ health บอกว่าโหมด prototype เปิด หน้าตาของแบนเนอร์เป็นเรื่องของหน้าจอ (API-D23)
