แพ็กนี้คือกติกากลางของงานที่ไม่ได้ทำใน request: งานไหนต้องทำเบื้องหลัง รอบเวลาอยู่ที่ไหน รันซ้อนกันได้ไหม ลองใหม่อย่างไร อะไรเป็น Failed รอบหนึ่งบันทึกอะไร ใครดูและสั่งรันได้ และเตือนใครเมื่อล้มซ้ำ ทุกงานมีรหัสใน catalog ในโค้ด ทุกรอบเป็นแถวหนึ่งใน `job_run` และฐานข้อมูลเป็นตัวตัดสินว่ารันซ้อนหรือไม่ จึงใช้ได้ทั้งเครื่องเดียวและหลาย container

## ครอบคลุม

- งานแบบไหนต้องทำเบื้องหลัง และทำไม request จึงไม่รอ
- งานตามรอบเวลา (recurring) และงานครั้งเดียวที่ request เข้าคิว (one-off) ใน transaction เดียวกับการบันทึก
- รอบเวลาที่เก็บในฐานข้อมูล สามรูปแบบบนจอ เขตเวลาของระบบ
- รันทีละรอบแม้มีหลาย container และการกันงานครั้งเดียวซ้ำ
- งานที่รันซ้ำได้ปลอดภัย การแบ่งทีละรายการ
- การลองใหม่ จำนวนครั้ง ระยะห่าง และอะไรเป็น Failed
- งานที่นานเกินกำหนด และงานที่ตายไปกับ process
- สิ่งที่บันทึกต่อรอบ อายุการเก็บ และการไม่บันทึกรอบที่ไม่มีงาน
- จองาน: รายการงาน ประวัติรอบ สั่งรันด้วยมือ ลองใหม่งานที่ล้ม แก้รอบเวลา เปิดปิด
- การเตือนเมื่อล้มติดกันหลายรอบ
- ผู้ทำ `SYSTEM` และ Activity Log ของงาน
- การปิดงานโดยไม่ deploy, งานใน test, ตอน start และตอนปิดระบบ, รันใน API หรือแยก worker

## ไม่รวม

- ตัวงานแต่ละงานและกติกาของรายการในงานนั้น เช่นลำดับอีเมล อายุของไฟล์ที่พัก: แพ็กเจ้าของงานหรือโปรเจกต์ แพ็กนี้บอกแค่ว่างานต้องรันอย่างไร
- บันทึกรายรายการของงาน (log ของอีเมลแต่ละฉบับ log ของไฟล์ที่ซิงก์): เป็นตารางของงานนั้น แพ็กนี้เก็บแค่จำนวนต่อรอบ
- การเชื่อมระบบภายนอกและการนำเข้าส่งออกไฟล์: เรื่องของแพ็กหรือโปรเจกต์ที่เกี่ยว ถ้าทำเป็นงานเบื้องหลังก็ใช้กติกาแพ็กนี้
- message broker แยกต่างหาก เช่น RabbitMQ: ไม่มีในรุ่นนี้ คิวอยู่ใน PostgreSQL
- การแก้ cron เป็นข้อความอิสระบนจอ: ไม่มีในรุ่นนี้ ดู JOB-D03
- ช่องสิทธิ์และกลุ่มที่ถือ: แพ็ก `permission` แพ็กนี้ใช้แค่ชื่อคีย์ของโปรเจกต์

## งานของแพ็กอื่น

แพ็ก `auth` `mail` และ `upload` มีงานของตัวเอง (งานล้างข้อมูลการเข้าระบบ ตัวส่งอีเมล งานล้างไฟล์ที่พักและเนื้อไฟล์ที่เอาออก) แต่ไม่ได้บอกว่างานรันอย่างไร เมื่อโปรเจกต์เลือกแพ็กนี้ งานเหล่านั้นทำตามแพ็กนี้ทุกข้อ: เป็นรายการใน catalog อยู่บนจองาน และรันทีละรอบตาม JOB-D05 แพ็กเจ้าของงานยังเป็นคนกำหนดรอบเวลา เงื่อนไขของงาน และการลองใหม่ของแต่ละรายการ จึงแก้รอบบนจอไม่ได้ แต่เปิดปิดได้ (JOB-D03, JOB-D07) ถ้าโปรเจกต์ไม่เลือกแพ็กนี้ งานเหล่านั้นทำตามแพ็กของมันเอง
