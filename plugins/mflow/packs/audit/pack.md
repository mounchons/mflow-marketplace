แพ็กฐานของทุกระบบ: ทุกแถวรู้ว่าใครสร้างและแก้เมื่อไร ข้อมูลธุรกิจไม่ถูกลบจริง และทุกการเปลี่ยนแปลงทิ้งรายการใน Activity Log ที่มีค่าเก่าและค่าใหม่ เขียนใน transaction เดียวกับงาน แพ็กอื่น (`auth`, `users`, `permission`, `mail`) ใช้กติกาของแพ็กนี้

## ครอบคลุม

- ทะเบียนผู้ทำกลาง (`actor`) ของคนทุกพอร์ทัล และผู้ทำที่เป็นระบบหนึ่งแถว
- คอลัมน์ผู้ทำและเวลา (`created_*`, `updated_*`) ที่ระบบตั้งเองตอนบันทึก
- soft delete ด้วยคอลัมน์ชุดเดียวทั้งระบบ ซ่อนด้วย filter ชื่อเดียว และค่าที่ห้ามซ้ำใช้ซ้ำได้หลังลบ
- ลบจริงเฉพาะตารางชั่วคราวทางเทคนิค ตามอายุ
- คีย์หลัก uuid v7 และการกันการแก้ทับกันเมื่อหลายคนแก้แถวเดียว
- Activity Log: หนึ่งรายการต่อหนึ่งการบันทึก ค่าเก่าและค่าใหม่ ฟิลด์ลับไม่มีค่า แก้หรือลบไม่ได้ เก็บอย่างน้อยตามที่กำหนด
- จอ Activity Log: ใครเห็นแถวไหน ตัวกรอง แท็บพร้อมจำนวน รายละเอียดของรายการ ชื่อผู้ทำ

## ไม่รวม

- ใครถือสิทธิ์ดู log (แพ็ก `permission`) และ log การเข้าระบบแต่ละแบบ (แพ็ก `auth`) แพ็กนี้กำหนดแค่ว่าบันทึกอย่างไรและแสดงอย่างไร
- การ export log และการลบข้อมูลส่วนบุคคลตามคำขอ (ยังไม่มีคำตอบมาตรฐาน ดู AUDIT-D15)
- ภาษาของป้ายบนจอ: ตามกติกาของโปรเจกต์ ค่าเริ่มต้นเป็นคู่ `English · ไทย` โปรเจกต์ภาษาเดียวใช้ครึ่งเดียว

## คำของโปรเจกต์

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{account_kinds}` | ชนิดของบัญชีที่ทะเบียนผู้ทำรู้จัก นอกจาก System | `Staff`, `Partner` |
| `{business_documents}` | ชนิดเอกสารธุรกิจที่ไปอยู่แท็บ Documents | `Order`, `Invoice` |
| `{document_types}` | ชนิดเอกสารทั้งหมดที่เลือกในตัวกรองได้ | `Order`, `Account`, `Group`, `SystemSetting` |
| `{log_view_key}` | สิทธิ์ดูจอ Activity Log | `ActivityLog.View` |
| `{log_view_all_key}` | สิทธิ์ดูแถวของทุกคน | `ActivityLog.ViewAll` |
| `{api_prefix}` | ส่วนหน้าของ route API | `/api/v1` |
