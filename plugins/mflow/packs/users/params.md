# ค่าเริ่มต้นของแพ็ก users

ค่าที่เอกสารลูกค้าระบุแทนค่าเริ่มต้น จำนวนลิงก์ต่อชั่วโมงนับรวมกับลิงก์ลืมรหัสผ่านของแพ็ก auth เฉพาะค่าที่กำกับ `ตั้งบนจอ` อยู่บนหน้าตั้งค่าระบบ (แพ็กนี้ยังไม่มีค่าที่กำกับ) นอกนั้นอยู่ในโค้ดหรือ config

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| ขนาดหน้าของรายการ | `users.page_sizes` | 20, 50, 100 | ตัวเลือก 1–4 ค่า | แบ่งหน้าที่ server |
| ลิงก์รหัสต่อบัญชีต่อชั่วโมง | `users.reset_links_per_hour` | 3 | 1–10 | ลิงก์ที่เกินถูกปฏิเสธพร้อมข้อความ |
| ความยาวรหัสเริ่มต้นของการเชิญ | `users.initial_password_length` | 12 | ภายในนโยบายรหัสของ auth | มีตัวพิมพ์ใหญ่ เล็ก และตัวเลข |
| อายุการเชิญ | `users.invite_hours` | 24 | 1–168 ชั่วโมง | หลังจากนั้นต้องเชิญใหม่ |
| ล้างรหัสที่เข้ารหัสในคิวอีเมล | `users.queued_secret_hours` | 24 | 1–168 ชั่วโมง | นับจากเวลาเข้าคิว |
| บัญชีต่อองค์กร | `users.org_account_limit` | 3 | 1–100 หรือไม่จำกัด | นับเฉพาะบัญชีที่ยังไม่ถูกลบ |
| ความยาวอีเมล | `users.email_max_length` | 254 | ตายตัว | ตามมาตรฐานอีเมล |
| ความยาวชื่อ | `users.name_max_length` | 200 | 50–500 | ชื่อเต็มและชื่อผู้ติดต่อ |
| ความยาวเบอร์โทร | `users.phone_max_length` | 30 | 15–50 | ไม่บังคับกรอก |
