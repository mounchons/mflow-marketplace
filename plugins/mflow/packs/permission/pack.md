## ครอบคลุม

- catalog ของหน้าจอ ช่องสิทธิ์ (View, Manage และช่องเขียนอื่น) และคำสั่งละเอียด (`<SCREEN>.<Action>`) ที่กำหนดในโค้ดและเปลี่ยนผ่าน migration เท่านั้น
- กลุ่มถือสิทธิ์ต่อหน้าจอ ผู้ใช้ได้สิทธิ์จากกลุ่มเท่านั้น ไม่มีสิทธิ์รายคน
- คีย์ของผู้ใช้ปัจจุบันคำนวณตอนเข้าระบบ (`GET /me`) และสิทธิ์ที่เปลี่ยนมีผลรอบเข้าถัดไป
- ตรวจฝั่ง server ทุก endpoint (ประกาศคีย์ทุกตัว มี architecture test) หน้าจอซ่อนเมนูและปุ่มตามคีย์ แต่ server เป็นผู้ตัดสิน
- Activity Log บันทึก role ของผู้ทำ ณ เวลาที่ทำ
- ขอบเขตข้อมูลต่อกลุ่มต่อเมนูตามมิติ `{scope}` (ทั้งหมด หรือรายการรหัส) บังคับด้วย filter เดียวที่ปิดไม่ได้ นอกขอบเขตตอบ not found
- กลุ่ม seed, กลุ่มใหม่, การแยกช่องสิทธิ์ภายหลังโดยไม่มีใครเสียปุ่ม
- จอจัดการกลุ่ม: รายการ สร้าง เปลี่ยนชื่อ ติ๊กสิทธิ์ต่อหน้าจอ ตั้งขอบเขตต่อเมนู ดูสมาชิก บันทึกทุกการเปลี่ยน
- role ของบัญชีใน `{org_portal}` (เมนูต่อ role, role `{org_admin}` ที่ล็อกไว้) เมื่อระบบมีพอร์ทัลขององค์กรภายนอก
- ตัวสลับผู้ใช้ของ prototype บน `{staff_portal}`

## ไม่รวม

- บัญชี การเข้าระบบ เซสชัน และหน้าเข้าครั้งแรก: แพ็ก `auth`
- จอจัดการผู้ใช้และการย้ายผู้ใช้เข้ากลุ่ม: แพ็ก `users`
- จอ Activity Log และรูปแบบของ log: แพ็ก `audit`
- กลุ่มผู้รับข่าวหรือประกาศ (audience group): เป็นของเรื่องข่าวสาร ไม่ใช่สิทธิ์
- ข้อยกเว้นที่ขยายขอบเขตจากข้อมูลในเอกสาร (เช่น ผู้ใช้เห็นเอกสารที่มีรหัสของตัวเองแม้อยู่นอกขอบเขตกลุ่ม): เป็นกติกาของโปรเจกต์ คุยใน discuss ของโปรเจกต์นั้น
- รายชื่อกลุ่ม role และสิทธิ์จริงของแต่ละกลุ่ม: มาจากเอกสารลูกค้า (PERM-D15)

## คำของโปรเจกต์

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{staff_portal}` | พอร์ทัลของพนักงานที่ใช้กลุ่มและสิทธิ์รายหน้าจอ | back office |
| `{org_portal}` | พอร์ทัลขององค์กรภายนอกที่ใช้ role ต่อเมนู | พอร์ทัลลูกค้า, พอร์ทัลคู่ค้า |
| `{org}` | องค์กรภายนอกที่บัญชีใน `{org_portal}` สังกัด | บริษัทลูกค้า, คู่ค้า, ตัวแทน |
| `{scope}` | มิติที่แบ่งว่ากลุ่มเห็นข้อมูลของใคร | สาขา, บริษัท, ลูกค้า, คู่ค้า |
| `{superadmin}` | กลุ่มผู้ดูแลสูงสุดใน seed | SuperAdmin |
| `{org_admin}` | role ผู้ดูแลของแต่ละ `{org}` ที่ล็อกไว้ | Org admin |

ถ้าระบบมีพอร์ทัลเดียว ส่วนของ `{org_portal}`, `{org}` และ `{org_admin}` ไม่ใช้ และขอบเขตของบัญชีภายนอกตัดออก
