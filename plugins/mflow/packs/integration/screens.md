# integration screens

| หน้าจอ | ทำอะไร | ใครใช้ | หมายเหตุ |
|---|---|---|---|
| จอติดตามการเชื่อมต่อ | ตารางต่อ `{external_system}` และ `{operation}` (ครั้ง สำเร็จ เตือน ล้ม ผลล่าสุด เวลาเฉลี่ย cursor), รายการที่ล้มพร้อมรหัสอ้างอิง, คิวงานเขียนที่รอ, รอบงานล่าสุดจากแพ็ก jobs, ป้าย `fake` หรือ `ยังไม่ได้ตั้ง` | ผู้ถือ `{integration_view_key}` | เปิดมาที่ `integration.monitor_hours` ชั่วโมงล่าสุด แถวรายเอกสารเห็นเฉพาะผู้ที่ขอบเขตเป็นทั้งหมด (INTG-D15) ค้างเกิน `integration.late_hours` ชั่วโมงเป็นสีแดง โหลดไม่ได้แสดง error พร้อม Retry ไม่แสดง 0 |
| กล่องส่งซ้ำ | บอกระบบ เส้น เจ้าของรายการ และสาเหตุเดิม กรอกเหตุผล กด Re-send | ผู้ถือ `{integration_manage_key}` | ใช้คีย์กันซ้ำเดิม ลง Activity Log แสดงเฉพาะแถว Failed หรือ Review ไม่แสดงเนื้อหาที่ปิดบัง |
| กล่องดึงซ้ำ | เลือกจาก cursor หรือจากเวลาที่เลือก บอกว่าจะเขียนข้อมูลเข้า และใช้เวลาหลายนาที | ผู้ถือ `{integration_manage_key}` | เป็นการสั่งรันด้วยมือของแพ็ก jobs ย้อนได้ไม่เกิน `integration.repull_max_days` วัน การดึงย้อนหลังไม่ขยับ cursor |
| แท็บ `<ชื่อระบบ>` บนหน้าตั้งค่าระบบ | address, ผู้ใช้, รหัสผ่านหรือ API key, กุญแจลายเซ็น webhook เมื่อมี, ปุ่ม Test connection พร้อมผลในแท็บ | ผู้จัดการค่าตั้ง | หน้าตั้งค่าเป็นของแพ็ก settings ความลับแสดงเป็นตั้งแล้วหรือยังไม่ตั้ง |
| ข้อความผิดของเส้นที่เรียกอีกฝั่ง | บอกว่าระบบใดตอบไม่ได้ พร้อมรหัสอ้างอิงที่คัดลอกได้ | ผู้ใช้ทุกคน | ข้อความเป็นถ้อยคำของคน ไม่มีรหัสของอีกฝั่ง ไม่มี URL |
| ป้ายเวลาที่ดึงล่าสุด บนหน้าที่แสดงข้อมูลจากอีกฝั่ง | เวลาที่ดึงมาล่าสุด เมื่ออีกฝั่งไม่พร้อม | ผู้ใช้ที่เปิดหน้า | ข้อมูลเก่ายังแสดงได้ ไม่มี error ทั้งหน้า (INTG-D12) |
