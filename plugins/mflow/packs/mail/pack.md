# แพ็ก mail: คิวอีเมล การส่ง และเทมเพลต

ทุกอีเมลที่ระบบส่งเข้าคิวในตาราง `mail_outbox` ใน transaction เดียวกับงานที่ทำให้เกิดอีเมล แล้วตัวส่งตัวเดียวหยิบไปส่งผ่าน SMTP พร้อมบันทึกทุกครั้งที่พยายามส่ง ผู้ดูแลแก้ข้อความของเทมเพลต ทำสำเนา และผูกเหตุการณ์กับเทมเพลตได้บนหน้าจอ ส่วนเหตุการณ์ที่ส่งอีเมลกำหนดในโค้ด

## ครอบคลุม

- คิว `mail_outbox` ที่เข้าใน transaction เดียวกับงาน และสถานะ Queued, Sent, Skipped, Failed
- ตัวส่งตัวเดียวต่อครั้ง ลำดับการหยิบ การตัดสินแต่ละฉบับตอนหยิบ retry และ `mail_log` ของทุกครั้งที่พยายามส่ง
- สวิตช์ส่งจริง (ค่าเริ่มปิด) และจุดเริ่มส่งที่กันอีเมลเก่าไหลออก, allow-list ผู้รับ, จำกัดจำนวนต่อชั่วโมง
- ผู้ส่งเดียวของระบบ, SMTP ผ่าน TLS เท่านั้น, ค่า SMTP จาก env ตรวจตอน start
- ผู้รับของอีเมลถึงบัญชีเดียว และถึง `{org}` ที่มีหลายบัญชี
- ความลับในอีเมล (รหัสผ่านเริ่มต้น โทเค็นลิงก์ รหัส OTP) เก็บเข้ารหัส ล้างตามเวลา และปิดบังใน log
- ทะเบียนเทมเพลตระบบ (key ตายตัว) และสำเนาของผู้ใช้, แท็ก, แท็กบังคับของอีเมลบัญชี, preview, สวิตช์เปิดปิด, คัดลอก, ลบสำเนา
- จอผูกเหตุการณ์กับเทมเพลตเป็นขั้น (step) มีสวิตช์ต่อขั้น บันทึกทั้งชุด และคืนค่าเริ่มต้น
- หน้า mailbox ของ prototype ที่แสดงอีเมลในคิวโดยไม่ต้องมี SMTP

อีเมลบัญชีที่แพ็กอื่นใช้ เป็นเทมเพลตระบบที่ส่งเสมอ ปิดไม่ได้ และไม่มีแถวบนจอผูก:

| key | ใช้เมื่อ | แท็กบังคับ |
|---|---|---|
| `account.invite` | สร้างบัญชีที่ได้รหัสผ่านเริ่มต้นทางอีเมล | `{{temp_password}}`, `{{confirm_link}}` |
| `account.password_link` | ลืมรหัสผ่าน, ผู้ดูแลสร้างผู้ใช้ใหม่ หรือรีเซ็ตรหัสให้ | `{{reset_link}}` |
| `account.sign_in_code` | ผ่านรหัสผ่านแล้วต้องยืนยันด้วยรหัสทางอีเมล | `{{code}}` |

## ไม่รวม

- รายการเหตุการณ์ทางธุรกิจที่ส่งอีเมล ข้อความจริงของแต่ละเทมเพลต และแท็กเฉพาะของเหตุการณ์ (ของแต่ละโปรเจกต์ ดู MAIL-D03)
- การเปิดปิด OTP และอายุของรหัส (แพ็ก auth), หน้าตั้งค่าระบบทั้งหน้า (แพ็ก settings ในรอบถัดไป)
- อีเมลการตลาด จดหมายข่าว การยกเลิกรับ (unsubscribe), การรับอีเมลเข้า, SMS และ push notification
- การตั้ง SPF, DKIM, DMARC ของโดเมนผู้ส่ง (งานของผู้ดูแล mail server)

## คำของโปรเจกต์

| คำ | ความหมาย |
|---|---|
| `{portal}` | เว็บแต่ละตัวที่ผู้ใช้เข้าระบบ แต่ละตัวมี URL ของตัวเอง |
| `{org}` | หน่วยที่มีหลายบัญชีและรับอีเมลร่วมกัน เช่น บริษัทคู่ค้า สาขา |
| `{area}` | เมนูหรือส่วนของระบบที่อีเมลฉบับหนึ่งเป็นเรื่องของ ใช้เลือกผู้รับใน `{org}` |
| `{company_name}` | แท็กชื่อบริษัทผู้ส่ง จากค่า `mail.company_name` |
| `{portal_url}` | แท็ก URL ของ `{portal}` ของผู้รับ |
| `{contact_name}` | แท็กชื่อผู้รับ |
| `{temp_password}`, `{confirm_link}`, `{reset_link}`, `{code}` | แท็กความลับของอีเมลบัญชี |
| `{order_no}` | ตัวอย่างแท็กของเหตุการณ์หนึ่งในสถานการณ์ของ requirements.md แท็กของเหตุการณ์จริงเป็นของโปรเจกต์ (MAIL-D03) |
