# หน้าจอของแพ็ก settings

| หน้าจอ | ทำอะไร | ใครเข้าได้ | ส่วนสำคัญ |
|---|---|---|---|
| System settings · ตั้งค่าระบบ (`/settings`) | ดูและแก้ค่าของระบบ แท็บละหนึ่งแพ็กหรือหนึ่งเรื่อง | ผู้ถือ `{settings_view_key}` อ่านอย่างเดียว, ผู้ถือ `{settings_manage_key}` บันทึกได้ | แท็บอยู่ใน address, ทุกช่องมีชื่อ ค่าพร้อมหน่วย ช่วงหรือตัวเลือก ค่าเริ่มต้น และสองบรรทัด "คืออะไร" กับ "ปรับแล้ว", ค่าต่อพอร์ทัลมีช่องกรอกต่อพอร์ทัล, ความลับแสดงแค่ตั้งแล้วหรือยังพร้อมปุ่ม Clear, ป้ายเมื่อถูก env บังคับ, Default ต่อช่อง, Save, Cancel, Reset tab, หมายเหตุและปุ่มของแพ็กเจ้าของ |
| กล่องยืนยันการเปลี่ยนที่อันตราย | แสดงทุกการเปลี่ยนที่ต้องยืนยันเป็นประโยคก่อนส่ง | ผู้ถือ `{settings_manage_key}` | ชื่อ ค่าเดิม ค่าใหม่ และผล, ปุ่ม Save แบบ danger, Cancel ไม่ส่งอะไรและคงร่าง |
| กล่องถามก่อนทิ้งการแก้ | ถามเมื่อเปลี่ยนแท็บหรือออกจากหน้าตอนมีร่าง | ผู้ถือ `{settings_manage_key}` | Stay คงแท็บและร่าง, Discard ทิ้งร่าง |
| แถบแจ้งมีคนแก้ก่อน | แสดงเมื่อ API ตอบ 409 | ผู้ถือ `{settings_manage_key}` | ปุ่ม Reload, ร่างยังอยู่จนกด Reload |

ไม่มี View แล้วไม่มีเมนู และเปิดด้วย URL ได้แผง no-access ประวัติการเปลี่ยนดูในจอ Activity Log ของแพ็ก `audit` โดยกรองชนิดเอกสาร `SystemSetting`
