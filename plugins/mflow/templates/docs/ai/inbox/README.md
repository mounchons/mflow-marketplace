# AI inbox

Results from other AI tools (Codex, Gemini, ChatGPT…) land here, one Markdown file each, with frontmatter `status: new`. Briefs that produced them live in `.mflow/briefs/`.

Nothing here is trusted until `/mflow:assess` has checked it against the code, specs and sources. The assessment is written next to the file as `<name>.assessment.md`, and the file's status becomes `assessed`.
