แพ็กฐานของระบบที่มี API: ทุก endpoint อยู่ใต้ route ที่มีรุ่น ตอบ error แบบเดียวกัน แบ่งหน้า เรียง และค้นแบบเดียวกัน ส่งวันเวลาแบบเดียวกัน และกันการแก้ทับด้วยเลขรุ่นของระเบียน พร้อมสภาพแวดล้อมที่รันระบบ: คำสั่งเดียวเปิดทั้งชุด proxy ตัวเดียวอยู่ข้างหน้า ความลับมาจาก env และสี่สภาพแวดล้อมที่ต่างกันชัด แพ็กอื่น (`auth`, `permission`, `users`, `mail`, `audit`) ใช้รหัส error สถานะ HTTP และรูปแบบรายการของแพ็กนี้

## ครอบคลุม

- route ใต้ `/api/v1` ชื่อ resource รูปแบบ JSON method และสถานะเมื่อสำเร็จ การเปลี่ยน API ที่ทำให้ client เดิมพัง
- error body แบบ RFC 9457 ที่มี `code` ไม่เปลี่ยน `requestId` และ error รายฟิลด์ ตารางสถานะ HTTP ที่ใช้ (รวม 404 ของระเบียนนอกขอบเขต และ 409)
- เลขรุ่นของระเบียนบนสาย และ 409 เมื่อบันทึกจากข้อมูลเก่า
- รายการแบบแบ่งหน้า การเรียง และการค้นหา
- วันเวลาบนสาย เขตเวลาของระบบ และนาฬิกาตัวเดียวที่ test แทนได้
- health และ readiness, OpenAPI contract ที่ commit ไว้ และหน้าเอกสาร API ต่อสภาพแวดล้อม
- request id ทุกคำตอบ log แบบมีโครงสร้าง และไม่มีความลับใน log หรือคำตอบ
- จำกัดอัตราคำขอที่ไม่ได้เข้าระบบ CORS และขนาดคำขอสูงสุด
- reverse proxy ความลับจาก env คำสั่งเดียวเปิดทั้งชุด หน่วยความจำต่อ container และ migration ก่อนรับคำขอ
- สี่สภาพแวดล้อม (Development, Prototype, Staging, Production) และโหมด prototype
- ใช้กับ endpoint ที่ตอบ JSON เว็บที่ render ฝั่ง server ใช้สถานะ HTTP request id และ log ชุดเดียวกัน แต่ตอบเป็นหน้า HTML

## ไม่รวม

- การเข้าระบบ เซสชัน CSRF และการล็อกเมื่อเข้าผิดซ้ำ: แพ็ก `auth` แพ็กนี้บอกแค่สถานะและรหัสที่ใช้ร่วมกัน
- สิทธิ์ ขอบเขตข้อมูล และ Activity Log ของคำขอที่ถูกปฏิเสธ: แพ็ก `permission` แพ็กนี้บอกแค่ว่าระเบียนนอกขอบเขตตอบ 404
- คอลัมน์เลขรุ่น คีย์ uuid และการเก็บเวลาเป็น UTC ในตาราง: แพ็ก `audit`
- ขนาดไฟล์ที่อัปโหลดได้และชนิดไฟล์: เรื่องการอัปโหลด แพ็กนี้กำหนดแค่ขนาดคำขอสูงสุดที่ proxy และ API รับ
- API ที่เปิดให้ระบบภายนอกเรียก (API key, idempotency key, webhook) การเรียกระบบภายนอก และตัวจำลองของระบบเหล่านั้น: คุยในหัวข้อการเชื่อมระบบของโปรเจกต์
- รูปแบบวันที่และตัวเลขบนจอ หน้า error และแบนเนอร์ของเว็บ: เรื่องของหน้าจอ
- การเก็บ log ระยะยาว การ monitor และแจ้งเตือน backup และใบรับรอง HTTPS: infra ของลูกค้า

## คำของโปรเจกต์

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{portal}` | เว็บแต่ละตัวที่ proxy ให้บริการ ระบบที่มีเว็บเดียวใช้ชื่อเดียว | หลังบ้านของพนักงาน, พอร์ทัลลูกค้า |
