# ค่าเริ่มต้นของแพ็ก audit

ค่าที่เอกสารลูกค้าระบุแทนค่าเริ่มต้นได้

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| เหตุผลการลบยาวสุด | `audit.deleted_reason_max` | 500 ตัวอักษร | 100–2000 | ไม่บังคับกรอก |
| อายุขั้นต่ำของ Activity Log | `audit.log_retention_months` | 12 เดือน | 12 ขึ้นไป | ไม่มีงานล้าง log ในรุ่นแรก (AUDIT-D16) |
| อายุ log การเรียกระบบภายนอก | `audit.call_log_days` | 90 วัน | 30–365 | ตารางชั่วคราว ลบจริง ไม่ลง Activity Log |
| อายุข้อมูลรอนำเข้าที่ยืนยันหรือยกเลิกแล้ว | `audit.import_staging_closed_days` | 30 วัน | 1–90 | นับจากวันยืนยันหรือยกเลิก |
| อายุข้อมูลรอนำเข้าที่ค้าง | `audit.import_staging_open_days` | 1 วัน | 1–30 | นับจากการแก้ครั้งล่าสุด |
| จำนวนรายการต่อหน้าของ API | `audit.page_size_default` | 20 | 1 ถึงค่าสูงสุด | |
| จำนวนรายการต่อหน้าสูงสุดของ API | `audit.page_size_max` | 200 | 50–500 | |
| ตัวเลือกจำนวนแถวบนจอ | `audit.screen_page_sizes` | 20, 50, 100 | | ค่าแรกเป็นค่าเริ่มต้น |
| ช่วงวันที่ตอนเปิดจอ | `audit.default_range_days` | 7 วัน (วันนี้และ 6 วันก่อน) | 1–31 | ล้างตัวกรองแล้วกลับมาช่วงนี้ |
| วันที่เร็วสุดที่ค้นได้ | `audit.date_min` | 01/01/2000 | | นอกช่วงตอบ `VALIDATION_FAILED` |
| วันที่ช้าสุดที่ค้นได้ | `audit.date_max` | 31/12/2099 | | |
| แถวที่แสดงในรายละเอียดหนึ่งรายการ | `audit.detail_rows_max` | 20 | 5–100 | บอกจำนวนแถวทั้งหมดด้วย |
