# auth: หน้าจอ

ทุกหน้าใช้ layout ของการเข้าระบบ ไม่มีเมนูของพอร์ทัล สร้างจาก UI kit และมีครบในทุก `{portal}`

| หน้าจอ | path | ใช้ทำอะไร | ใครเห็น |
|---|---|---|---|
| เข้าสู่ระบบ | `/login` | อีเมล รหัสผ่าน ลิงก์ลืมรหัส บรรทัดบอกว่าติดต่อใคร ข้อความเมื่อมาจากเซสชันหมดเวลา (`?reason=timeout`) หรือรหัส OTP ใช้ไม่ได้ (`?reason=code`) | ทุกคนที่ยังไม่เข้าระบบ |
| ลืมรหัสผ่าน | `/forgot-password` | ใส่อีเมล ส่งลิงก์ แสดงข้อความกลางๆ | ทุกคนที่ยังไม่เข้าระบบ |
| ตั้งรหัสผ่านใหม่ | `/reset-password#token=` | ตรวจลิงก์ตอนเปิด รหัสใหม่ ยืนยัน กติการหัส บันทึกแล้วเสนอปุ่มเข้าระบบ หรือข้อความลิงก์หมดอายุพร้อมทางขอลิงก์ใหม่ | ผู้ที่เปิดลิงก์จากอีเมล |
| เข้าครั้งแรก | `/first-login` | ตั้งรหัสใหม่และ/หรือยอมรับ `{terms}` ตามที่ค้าง ข้ามไม่ได้ | บัญชีที่การเข้าครั้งแรกยังค้าง |
| รหัสยืนยัน (OTP) | `/sign-in-code` | อีเมลแบบปิดบางส่วน ช่องรหัส ส่งรหัสใหม่พร้อมนับถอยหลัง กลับไปหน้าเข้าระบบ | ผู้ที่ผ่านรหัสผ่านเมื่อสวิตช์ OTP ของพอร์ทัลเปิด |
| เมนูผู้ใช้ (ส่วนของทุกหน้า) | — | ชื่อที่แสดงและปุ่มออกจากระบบ | ทุกคนที่เข้าระบบแล้ว |
| ตัวสลับผู้ใช้ (แถบ PROTOTYPE) | — | สลับเป็นบัญชีอื่นของพอร์ทัลเดียวกัน เฉพาะโหมด prototype และพอร์ทัลที่ไม่เปิดสู่ internet | ผู้ที่เข้าระบบแล้วบน prototype |
