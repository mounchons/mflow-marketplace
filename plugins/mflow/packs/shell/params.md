# shell: ค่าเริ่มต้น

ค่าที่เอกสารลูกค้าระบุใช้แทนค่าเริ่มต้น ค่าวันเวลาและตัวเลขเป็นค่าของทั้งระบบ ทุก `{portal}` ใช้ค่าเดียวกัน เฉพาะค่าที่กำกับ `ตั้งบนจอ` อยู่บนหน้าตั้งค่าระบบ (แพ็กนี้ยังไม่มีค่าที่กำกับ) นอกนั้นอยู่ในโค้ดหรือ config

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| ลำดับภาษาในป้าย | `shell.label_order` | `English · ไทย` | `English · ไทย`, `ไทย · English` | ใช้เมื่อ SHELL-D07 เป็นป้ายสองภาษา คั่นด้วย ` · ` |
| เขตเวลาของระบบ | `shell.time_zone` | `Asia/Bangkok` | ชื่อเขตเวลา IANA | แสดงเวลาตามค่านี้ ไม่ตาม browser หรือ server ต้องเป็นค่าเดียวกับ `api.time_zone` เมื่อเลือกแพ็ก api |
| รูปแบบวันที่ | `shell.date_format` | `DD/MM/YYYY` | `DD/MM/YYYY`, `DD-MM-YYYY`, `DD.MM.YYYY`, `YYYY-MM-DD` | ช่องกรอกวันที่รับรูปแบบเดียวกัน |
| รูปแบบวันเวลา | `shell.datetime_format` | `DD/MM/YYYY HH:mm` | รูปแบบวันที่ตามด้วย `HH:mm` หรือ `HH:mm:ss` | 24 ชั่วโมง |
| ปีที่แสดง | `shell.calendar` | ค.ศ. | ค.ศ., พ.ศ. | ค่าที่ส่งให้ server เป็นปี ค.ศ. เสมอ |
| ทศนิยมของเงิน | `shell.money_decimals` | 2 | 0–4 | ปัดเศษที่ server |
| ตัวเลือกจำนวนแถวต่อหน้า | `shell.page_sizes` | 20, 50, 100 | ค่าละ 10–200 | ค่าแรกเป็นค่าเริ่มต้น ไม่เกินจำนวนต่อหน้าสูงสุดของ API |
| ตัวเลือกใน select สูงสุด | `shell.select_max` | 30 | 10–100 | รายการที่ยาวกว่านี้หรือโตตามข้อมูลใช้ช่องเลือก (SHELL-D14) |
| แถวต่อหน้าใน dialog ของช่องเลือก | `shell.picker_page_size` | 10 | 10–50 | |
| เวลาที่ toast สำเร็จแสดง (วินาที) | `shell.toast_seconds` | 5 | 3–10 | toast ของข้อผิดพลาดค้างจนผู้ใช้ปิด |
| คอนทราสต์ตัวอักษรต่ำสุด | `shell.text_contrast_min` | 4.5:1 | 4.5:1–7:1 | ตัวอักษรใหญ่และไอคอนอย่างน้อย 3:1 |
| browser ที่รองรับ | `shell.browsers` | Chrome, Edge, Firefox, Safari | | desktop; มือถือเมื่อเครื่องที่ kit รองรับรวมมือถือ |
| จำนวนรุ่นล่าสุดที่รองรับ | `shell.browser_versions` | 2 | 1–3 | นับรุ่นหลักล่าสุดของแต่ละ browser |
