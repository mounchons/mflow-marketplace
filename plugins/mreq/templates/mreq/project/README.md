# {{PROJECT_NAME}}: requirements

ชุด requirement ของระบบนี้ทั้งหมดอยู่ใน `mreq/` ไฟล์นี้เป็นจุดเริ่มอ่าน ทั้งสำหรับคนและสำหรับ AI ที่จะสร้างระบบจริง

| หมวด | อยู่ที่ | มีอะไร |
|---|---|---|
| ภาพรวม | `mreq/project/vision.md` | วัตถุประสงค์, ผู้ใช้และ role, ขอบเขต, สิ่งที่ไม่รวม, คุณภาพที่ต้องการ |
| สถานะงาน | `mreq/project/STATUS.md` | กำลังทำอะไร ขั้นถัดไป และบันทึกย่อ |
| งานต่อ | `mreq/project/followups.md` | งานที่ผู้สร้างต้องทำ และสิ่งที่ต้องตรวจตอนทดสอบใช้งาน |
| เอกสารลูกค้า | `mreq/source/` | ต้นฉบับจากลูกค้า ไม่แก้ไข |
| ข้อตกลง | `mreq/discuss/` | `AGENDA.md` (หัวข้อที่ควรคุย) และเอกสาร discuss แต่ละหัวข้อ ฉบับที่ `approved` คือสิ่งที่ตกลงแล้ว |
| หน้าตาระบบ | `mreq/ui/` | UI kit (`theme/`), กฎการใช้ kit (`design-system.md`), สัญญาของ component (`contracts/`), ผู้ใช้ตัวอย่างและ role (`data/`) |
| เทคโนโลยีและโครงโค้ด | `AGENTS.md` ที่ root | `## Stack` และ `## Architecture` จากเอกสาร `tech-stack` และ `code-structure` ที่อนุมัติแล้ว |

ถ้าข้อมูลสองที่ขัดกัน ให้ถือเอกสาร discuss ที่อนุมัติล่าสุดเป็นหลัก
