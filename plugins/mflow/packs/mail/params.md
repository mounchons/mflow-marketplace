# MAIL: ค่าเริ่มต้น

ค่าที่เอกสารลูกค้าระบุแทนค่าเริ่มต้นได้เสมอ ค่าที่ตั้งบนจอได้อยู่ในหน้าตั้งค่าระบบ (MAIL-D25) นอกนั้นอยู่ในโค้ดหรือ env

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| จำนวนข้อความต่อ 60 นาที | `mail.max_per_hour` | 100 | 1–10,000 | ตั้งบนจอ มีผลรอบส่งถัดไป |
| allow-list ผู้รับ | `mail.allow_list` | ว่าง (ส่งทุกคน) | โดเมนพร้อม `@` และที่อยู่ คั่นด้วยจุลภาค ไม่เกิน 2,000 ตัวอักษร | ตั้งบนจอ ทำให้ว่างต้องยืนยัน |
| ชื่อบริษัทผู้ส่ง | `mail.company_name` | ชื่อบริษัทของลูกค้า | 1–200 ตัวอักษร | ค่าของแท็ก `{{company_name}}` |
| ตัวส่งดูคิวทุก | `mail.poll_seconds` | 60 | 15–600 วินาที | |
| รอก่อนลองใหม่ | `mail.retry_minutes` | 1 แล้ว 5 | | นับจากครั้งที่ไม่สำเร็จ |
| จำนวนครั้งที่ลองส่ง | `mail.max_attempts` | 3 | 1–10 | ครบแล้วเป็น Failed |
| ล้างความลับของอีเมลเชิญและลิงก์ | `mail.secret_hours` | 24 | 1–168 ชั่วโมง | ตรงกับอายุลิงก์ตั้งรหัส |
| ล้างรหัสเข้าระบบที่ไม่ถูกใช้ | `mail.code_secret_grace_minutes` | 60 | 15–1,440 นาที | นับหลังรหัสหมดอายุ |
| หัวเรื่องยาวสุด | `mail.subject_max` | 500 | | ตัวอักษร |
| ชื่อเทมเพลตยาวสุด | `mail.template_name_max` | 150 | | ตัวอักษร ต่อภาษา |
| port ของ STARTTLS | `mail.smtp_port_starttls` | 25 | | ใช้เมื่อ env ไม่ระบุ port |
| port ของ TLS | `mail.smtp_port_tls` | 465 | | ใช้เมื่อ env ไม่ระบุ port |
| รูปแบบวันที่ในอีเมล | `mail.date_format` | DD/MM/YYYY | | ตาม time zone ของระบบ |
