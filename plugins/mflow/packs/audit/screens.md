# หน้าจอของแพ็ก audit

| หน้าจอ | ทำอะไร | ใครเข้าได้ | ส่วนสำคัญ |
|---|---|---|---|
| Activity Log · บันทึกการใช้งาน | ดูว่าใครทำอะไรกับเอกสารไหนเมื่อไร อ่านอย่างเดียว | ผู้ถือ `{log_view_key}` (เห็นเฉพาะของตัวเอง) และ `{log_view_all_key}` (เห็นทุกแถว) | ตัวกรอง ผู้ใช้ / กลุ่มการกระทำ / ชนิดเอกสาร / ช่วงวันที่, หมายเหตุ "ดูเฉพาะการดำเนินการของตนเอง", แท็บสี่แท็บพร้อมจำนวน, ตารางแบ่งหน้าเรียงใหม่สุดก่อน, เปิดรายละเอียดใต้แถว, ไม่มีปุ่มแก้ ลบ หรือ export |

รายละเอียดของรายการเปิดใต้แถวในตาราง ไม่ใช่หน้าแยก ประวัติของเอกสารหรือบัญชีหนึ่งรายการ (เช่นแท็บประวัติในหน้ารายละเอียดบัญชี) อ่านจาก API เดียวกันโดยกรองชนิดและ id ของเอกสาร
