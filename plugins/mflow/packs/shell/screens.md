# หน้าจอของแพ็ก shell

| หน้าจอ | ทำอะไร | ใครเข้าได้ | ส่วนสำคัญ |
|---|---|---|---|
| layout ของ `{portal}` | กรอบของทุกหน้าที่เข้าระบบแล้วในพอร์ทัลนั้น | ผู้ใช้ที่เข้าระบบของ `{portal}` นั้น | sidebar ตามคีย์ (เต็ม / แถบไอคอน / drawer), top bar พร้อม ☰ และเมนูผู้ใช้ (Profile, Sign out), พื้นที่หลัก, ที่วาง toast, ชื่อแท็บ "ชื่อหน้า · `{app_name}`" |
| layout เข้าระบบ | กรอบของหน้าเข้าระบบ ลืมรหัส และเข้าครั้งแรก | ทุกคน | ไม่มี sidebar ไม่มีเมนู เนื้อหาของแพ็ก auth อยู่ข้างใน |
| layout สาธารณะ | กรอบของหน้าที่เปิดได้โดยไม่เข้าระบบ เมื่อระบบมี | ทุกคน | ไม่มีเมนูของพอร์ทัล ลิงก์ไปหน้าเข้าระบบ |
| ไม่พบหน้า (404) | แจ้งว่า address นี้ไม่มี | ทุกคน (ใน layout ของพอร์ทัลเมื่อเข้าระบบแล้ว) | ข้อความสองภาษาตาม SHELL-D07, ลิงก์ไป `{start_page}` |
| ระบบขัดข้อง (500) | แจ้งข้อผิดพลาดที่ไม่คาดคิด | ทุกคน | ข้อความกลางๆ, เลขอ้างอิงของคำขอ, ปุ่มลองใหม่, ไม่มีรายละเอียดทางเทคนิค |
| style guide | แสดงทุก component ทุกสถานะ ให้ทีมและลูกค้าตรวจ kit | เครื่องพัฒนา เครื่องทดสอบ และโหมด prototype เท่านั้น | ทุก component ทุกสถานะ, ตัวอย่างหน้ารายการ ฟอร์ม และหน้ารายละเอียดพร้อมส่วนประวัติ |

ส่วนที่อยู่ในหน้าจอของเรื่องอื่น ไม่ใช่หน้าแยก: ตารางรายการตาม SHELL-D11, dialog ของช่องเลือกระเบียน (ค้น แบ่งหน้า เลือกหนึ่ง ยืนยัน ยกเลิก), ส่วนประวัติท้ายหน้ารายละเอียด (เมื่อ โดย การกระทำ สถานะ หมายเหตุ), dialog ยืนยันก่อนออกจากหน้าที่ยังไม่บันทึก และ dialog ยืนยันก่อนลบหรือยกเลิกที่บอกชื่อรายการ แผง no-access เป็นของแพ็ก permission
