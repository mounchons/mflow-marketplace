# MAIL: ค่าเริ่มต้น

ค่าที่เอกสารลูกค้าระบุแทนค่าเริ่มต้นได้เสมอ เฉพาะค่าที่กำกับ `ตั้งบนจอ` อยู่ในหน้าตั้งค่าระบบของแพ็ก `settings` (MAIL-D25) นอกนั้นอยู่ในโค้ดหรือ env

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| จำนวนข้อความต่อ 60 นาที | `mail.max_per_hour` | 100 | 1–10,000 | ตั้งบนจอ มีผลรอบส่งถัดไป |
| allow-list ผู้รับ | `mail.allow_list` | ว่าง (ส่งทุกคน) | โดเมนพร้อม `@` และที่อยู่ คั่นด้วยจุลภาค ไม่เกิน 2,000 ตัวอักษร | ตั้งบนจอ ทำให้ว่างต้องยืนยัน |
| ชื่อบริษัทผู้ส่ง | `mail.company_name` | ชื่อบริษัทของลูกค้า | 1–200 ตัวอักษร | ตั้งบนจอ ค่าของแท็ก `{{company_name}}` |
| ตัวส่งดูคิวทุก | `mail.poll_seconds` | 60 | 15–600 วินาที | |
| รอก่อนลองใหม่ | `mail.retry_minutes` | 1 แล้ว 5 | | นับจากครั้งที่ไม่สำเร็จ |
| จำนวนครั้งที่ลองส่ง | `mail.max_attempts` | 3 | 1–10 | ครบแล้วเป็น Failed |
| ล้างความลับของอีเมลเชิญและลิงก์ | `mail.secret_hours` | 24 | 1–168 ชั่วโมง | ตรงกับอายุลิงก์ตั้งรหัส |
| ล้างรหัสเข้าระบบที่ไม่ถูกใช้ | `mail.code_secret_grace_minutes` | 60 | 15–1,440 นาที | นับหลังรหัสหมดอายุ |
| หัวเรื่องยาวสุด | `mail.subject_max` | 500 | | ตัวอักษร |
| ชื่อเทมเพลตยาวสุด | `mail.template_name_max` | 150 | | ตัวอักษร ต่อภาษา |
| SMTP host | `mail.smtp_host` | ว่าง | ชื่อ host หรือ IP ไม่เกิน 253 ตัวอักษร | ตั้งบนจอ ว่างอยู่ตัวส่งไม่ส่งและคงอีเมลในคิว (MAIL-D26) |
| SMTP port | `mail.smtp_port` | ว่าง | 1–65535 | ตั้งบนจอ ว่างคือใช้ port ของโหมด TLS ที่เลือก |
| โหมด TLS | `mail.smtp_tls` | starttls | starttls หรือ tls | ตั้งบนจอ (MAIL-D10) |
| port ของ STARTTLS | `mail.smtp_port_starttls` | 25 | | ใช้เมื่อไม่ได้ระบุ port |
| port ของ TLS | `mail.smtp_port_tls` | 465 | | ใช้เมื่อไม่ได้ระบุ port |
| ผู้ใช้ SMTP | `mail.smtp_user` | ว่าง | ไม่เกิน 256 ตัวอักษร | ตั้งบนจอ ยืนยันตัวตนเมื่อมีทั้งผู้ใช้และรหัส |
| รหัส SMTP | `mail.smtp_password` | ว่าง | ไม่เกิน 256 ตัวอักษร | ค่าความลับ เข้ารหัส ไม่แสดงกลับบนจอ |
| ลายนิ้วมือใบรับรอง | `mail.smtp_cert_sha256` | ว่าง | SHA-256 เลขฐานสิบหก 64 หลัก มีหรือไม่มี `:` ก็ได้ | ตั้งบนจอ สำหรับใบรับรองที่ลงนามเอง |
| ที่อยู่ผู้ส่ง | `mail.from_address` | ว่าง | อีเมลหนึ่งที่อยู่ | ตั้งบนจอ ว่างอยู่ตัวส่งไม่ส่ง |
| ชื่อผู้ส่ง | `mail.from_name` | ชื่อระบบ | 1–200 ตัวอักษร | ตั้งบนจอ |
| รอผลส่งทดสอบ | `mail.test_timeout_seconds` | 30 | 5–60 | ปุ่มส่งทดสอบ (MAIL-D30) |
| รูปแบบวันที่ในอีเมล | `mail.date_format` | DD/MM/YYYY | | ตาม time zone ของระบบ |
