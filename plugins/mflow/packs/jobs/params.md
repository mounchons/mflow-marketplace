# jobs: ค่าเริ่มต้น

เฉพาะค่าที่กำกับ `ตั้งบนจอ` อยู่บนหน้าตั้งค่าระบบ (แพ็ก settings) ถ้าโปรเจกต์ไม่มีหน้าตั้งค่า ค่าเหล่านี้อยู่ใน config ค่าอื่นอยู่ในโค้ดหรือ config ตอน deploy ค่าที่เอกสารลูกค้ากำหนดใช้แทนค่าเริ่มต้น

รอบเวลาและสวิตช์ของแต่ละงานอยู่บนจองาน ไม่อยู่ในตารางนี้ (JOB-D03, JOB-D17)

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| โหมดการรันงาน | `jobs.mode` | `Background` | `Background` หรือ `Inline` | `Inline` ใช้ใน test เท่านั้น (JOB-D18) |
| เครื่องนี้รับงาน | `jobs.runner` | `true` | `true` หรือ `false` | ตั้งจาก env `JOBS_RUNNER` (JOB-D17, JOB-D21) |
| งานพร้อมกันต่อเครื่อง | `jobs.worker_count` | 2 | 1–16 | |
| ตัวจับเวลาตรวจทุก (วินาที) | `jobs.tick_seconds` | 60 | 15–300 | |
| ดูคิวงานครั้งเดียวทุก (วินาที) | `jobs.poll_seconds` | 2 | 1–60 | เมื่อคิวว่าง |
| รอก่อนลองใหม่ (วินาที) | `jobs.retry_delays_seconds` | 30, 120 | ไม่เกิน 5 ค่า ค่าละ 1–3600 | จำนวนค่าคือจำนวนครั้งที่ลองใหม่ (JOB-D07) |
| เวลาสูงสุดต่อรอบ (นาที) | `jobs.timeout_minutes` | 60 | 1–1440 | ใช้เมื่อ catalog ไม่ระบุของงานนั้น |
| อายุ lease ของรอบที่รันอยู่ (วินาที) | `jobs.lease_seconds` | 60 | 30–600 | ต่ออายุทุกหนึ่งในสาม (JOB-D09) |
| เวลาที่ request รอได้ (วินาที) | `jobs.request_wait_seconds` | 3 | 1–30 | งานที่อาจนานกว่านี้ทำเบื้องหลัง (JOB-D01) |
| รอบถี่ที่ไม่บันทึกรอบว่าง (นาที) | `jobs.frequent_minutes` | 15 | 1–60 | งานที่รอบถี่กว่านี้และไม่มีงาน ไม่เขียนแถว (JOB-D10) |
| ข้อความ error ยาวสุด (ตัวอักษร) | `jobs.error_max` | 2000 | 200–4000 | |
| เก็บประวัติรอบ (วัน) | `jobs.run_retention_days` | 90 | 30–365 | นับจากเวลาจบ (JOB-D11) |
| เตือนเมื่อล้มติดกัน (รอบ) | `jobs.alert_after_failures` | 3 | 1–20 | ตั้งบนจอ |
| อีเมลรับการเตือน | `jobs.alert_emails` | ว่าง | list ของอีเมล | ตั้งบนจอ ทำให้ว่างต้องยืนยัน ว่างคือเตือนบนจออย่างเดียว (JOB-D14) |
| เวลาหยุดงานตอนปิดระบบ (วินาที) | `jobs.shutdown_seconds` | 30 | 10–120 | ตั้ง container ให้รอนานกว่านี้ (JOB-D20) |
| ตัวเลือกรอบ ทุก N นาที | `jobs.interval_minutes` | 5, 10, 15, 20, 30 | เลข 1–59 | บนฟอร์มแก้รอบเวลา (JOB-D03) |
