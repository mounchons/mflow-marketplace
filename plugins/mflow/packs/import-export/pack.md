แพ็กนี้คือกติกากลางของการนำเข้าข้อมูลจากไฟล์ Excel และการส่งออกรายการเป็นไฟล์ Excel การนำเข้าเป็นขั้นตอนเดียวทุกชนิดข้อมูล: อัปโหลด ตรวจทั้งไฟล์ เก็บแถวไว้ชั่วคราว แสดงแถวที่ผ่านและไม่ผ่าน ยืนยัน แล้วค่อยบันทึก แต่ละ `{import_target}` ต่างกันแค่นิยามคอลัมน์ การส่งออกใช้ query ตัวกรอง และขอบเขตข้อมูลเดียวกับรายการบนจอ และไฟล์ที่ออกไปต้องเปิดได้โดยไม่รันอะไรบนเครื่องผู้รับ

## ครอบคลุม

- นิยามคอลัมน์ชุดเดียวต่อ `{import_target}`: แม่แบบที่ดาวน์โหลดและตัวอ่านใช้ชุดเดียวกัน
- ไฟล์ที่รับ ขีดจำกัดแถว ขนาด และโครงสร้าง และการกันไฟล์ zip ที่แตกแล้วใหญ่เกินจริง
- การหาชีทและคอลัมน์จากหัวตาราง ชีทหลายชีท คอลัมน์เกิน หัวผิด แถวว่าง
- การอ่านค่าตามที่ Excel เก็บจริง: วันที่ พ.ศ. และ ค.ศ. ตัวเลข สูตร เซลล์ error รหัสที่ขึ้นต้นด้วยศูนย์
- ตรวจทั้งไฟล์ก่อนบันทึก แถวพัก หน้าผลตรวจพร้อมเลขแถว คอลัมน์ เหตุผล และรายงานข้อผิดให้ดาวน์โหลด
- เตือนและให้ดูแถวที่มีปัญหาก่อน ยืนยันแล้วนำเข้าเฉพาะแถวที่ผ่าน จับคู่รายการเดิม สิ่งที่การแก้เขียนทับได้ แถวซ้ำในไฟล์
- ใครนำเข้าได้ ขอบเขตข้อมูลต่อแถว ยืนยันและบันทึกใน transaction เดียว ยกเลิก
- ไฟล์ใหญ่เป็นงานเบื้องหลังพร้อมความคืบหน้า และการนำเข้าครั้งละหนึ่งชุดต่อชนิดข้อมูล
- Activity Log ของการนำเข้าและการส่งออก และการเก็บไฟล์ต้นฉบับ
- การส่งออก: รายการไหน คอลัมน์ไหน ตัวกรองและขอบเขต ขีดจำกัด งานเบื้องหลังพร้อมลิงก์หมดอายุ การกันสูตรในไฟล์ ไม่มีคอลัมน์ลับ และชื่อไฟล์
- หน้านำเข้า ปุ่มส่งออก รายการไฟล์ส่งออกของฉัน และค่าในแท็บ Import / Export ของหน้าตั้งค่าระบบ

## ไม่รวม

- การพิมพ์และเอกสาร PDF: ไม่อยู่ในแพ็กนี้ รายการตรวจของเรื่อง `import-export-print` ใน `topics.md` ยังถามเรื่องนี้ตามปกติ
- การตรวจเนื้อไฟล์ ที่เก็บไฟล์ และชื่อไฟล์ที่เก็บ: ใช้แพ็ก `upload` แพ็กนี้บอกแค่ว่าไฟล์นำเข้าต่างจากไฟล์แนบตรงไหน
- กลไกงานเบื้องหลัง คิว และการแจ้งเตือนเมื่องานจบ: เป็นของแพ็กงานเบื้องหลังเมื่อโปรเจกต์เลือก หรือกลไกที่โปรเจกต์มี
- คำสั่งสิทธิ์และขอบเขตข้อมูล: อยู่ในแพ็ก `permission` แพ็กนี้ใช้ชื่อคำสั่งของโปรเจกต์
- การดึงหรือส่งไฟล์กับระบบอื่นตามเวลา: เป็นเรื่องการเชื่อมระบบ
- การนำข้อมูลเก่าเข้าครั้งแรกตอนขึ้นระบบ: เป็นเรื่อง `data-migration` ถ้าใช้หน้านำเข้าก็ใช้กติกาของแพ็กนี้
- นิยามคอลัมน์ของแต่ละชนิดข้อมูล: เป็นของโปรเจกต์ แพ็กนี้บอกแค่ว่านิยามต้องมีอะไร
- การย้อนการนำเข้าที่บันทึกแล้วจากหน้าจอ: ไม่มีในรุ่นนี้ ดู IMPEX-D14

## คำของโปรเจกต์

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{import_target}` | ชนิดข้อมูลที่นำเข้าได้ แต่ละชนิดมีนิยามคอลัมน์ของตัวเอง | `Customer`, `Product` |
| `{match_key}` | คอลัมน์ที่ใช้จับคู่รายการเดิมของ `{import_target}` นั้น | `code` |
| `{list}` | รายการบนจอที่มีปุ่มส่งออก แต่ละรายการมีนิยามคอลัมน์ส่งออกของตัวเอง | `customers` |
| `{import_key}` | คำสั่งสิทธิ์นำเข้าของ `{import_target}` นั้น | `CUSTOMERS.Import` |
| `{export_key}` | คำสั่งสิทธิ์ส่งออกของ `{list}` นั้น | `CUSTOMERS.Export` |
| `{scope}` | มิติขอบเขตข้อมูลของโปรเจกต์ | สาขา, แผนก |
| `{portal}` | พอร์ทัลหรือเว็บที่มีหน้านำเข้าหรือปุ่มส่งออก | back office |
| `{api_prefix}` | ส่วนหน้าของ route API | `/api/v1` |
