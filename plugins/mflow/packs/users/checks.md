# สิ่งที่ลองตอนทดสอบใช้งาน

1. สร้างบัญชีพนักงานใหม่: ฟอร์มไม่มีช่องรหัสผ่าน บัญชีขึ้นเป็น Invited และอีเมลลิงก์ตั้งรหัสเข้าคิว (ดูได้ใน mailbox ของ prototype) ตั้งรหัสแล้วเข้าครั้งแรกจึงเป็น Active
2. ผู้ที่ถือสิทธิ์จอ Manage Users อย่างเดียว ลองสร้างบัญชีในกลุ่ม SuperAdmin และลองเปลี่ยนอีเมลของ SuperAdmin: ต้องถูกปฏิเสธทั้งสองครั้ง และ Activity Log บันทึกการปฏิเสธ
3. ปิดบัญชี (Disabled) ของคนที่กำลังใช้งานอยู่: request ถัดไปของคนนั้นหลุดจากระบบทันที แต่แก้แค่ชื่อแล้วเขาใช้งานต่อได้
4. ผู้ดูแลลองตั้งสถานะ ย้ายกลุ่ม หรือลบบัญชีของตัวเอง: ทุกครั้งถูกปฏิเสธพร้อมข้อความ
5. กด Reset password: ผู้ใช้ยังเข้าด้วยรหัสเดิมได้จนกว่าจะใช้ลิงก์ และกดเกินจำนวนต่อชั่วโมงแล้วได้ข้อความแจ้ง
6. ลบบัญชีแล้วสร้างบัญชีใหม่ด้วยชื่อผู้ใช้และอีเมลเดิม: สร้างได้ ส่วนบัญชีที่ลบเข้าระบบไม่ได้
7. เพิ่มบัญชีองค์กรด้วยอีเมลที่เป็นขององค์กรอื่นแล้ว: ถูกปฏิเสธโดยไม่บอกว่าเป็นขององค์กรไหน และเพิ่มเกินจำนวนต่อองค์กรไม่ได้
8. เปลี่ยนอีเมลของบัญชีองค์กรจากฝั่งพนักงาน: อีเมลเก่าและรหัสเก่าเข้าไม่ได้ บัญชีกลับเป็น Invited และอีเมลเชิญไปที่อีเมลใหม่เท่านั้น
9. บน Profile เปลี่ยนอีเมลโดยไม่ใส่รหัสปัจจุบัน: ไม่บันทึก ส่วนแก้แค่เบอร์บันทึกได้ทันที
10. เปิดดูรายละเอียดบัญชี ประวัติ และ Activity Log ทุกที่: ไม่มีรหัสผ่าน hash หรือ token ให้เห็นเลย
