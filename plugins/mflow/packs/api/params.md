# ค่าเริ่มต้นของแพ็ก api

ค่าที่เอกสารลูกค้าระบุแทนค่าเริ่มต้นได้ ค่าหน่วยความจำปรับตามเครื่องของลูกค้า เฉพาะค่าที่กำกับ `ตั้งบนจอ` อยู่บนหน้าตั้งค่าระบบ (แพ็กนี้ยังไม่มีค่าที่กำกับ) นอกนั้นอยู่ในโค้ดหรือ config

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| ส่วนหน้าของ route API | `api.route_prefix` | `/api/v1` | `/api/v` ตามด้วยเลขรุ่น | รุ่นใหม่เปิดเมื่อ API-D03 เป็นตัวเลือก b |
| จำนวนรายการต่อหน้า | `api.page_size_default` | 20 | 1 ถึงค่าสูงสุด | |
| จำนวนรายการต่อหน้าสูงสุด | `api.page_size_max` | 200 | 50–500 | เกินตอบ 400 ไม่ตัดให้เงียบๆ |
| คำค้นยาวสุด | `api.search_max_length` | 100 ตัวอักษร | 50–500 | นับหลังตัดช่องว่างหัวท้าย |
| เขตเวลาของระบบ | `api.time_zone` | `Asia/Bangkok` | ชื่อเขตเวลา IANA | ใช้คิดวันนี้ วันครบกำหนด และช่วงวันที่ ต้องเป็นค่าเดียวกับ `shell.time_zone` เมื่อเลือกแพ็ก shell |
| ภาษาของข้อความใน error | `api.message_language` | `English · ไทย` | ไทย / English / `English · ไทย` | ตามภาษาของป้ายบนจอ |
| ชื่อ header ของ request id | `api.request_id_header` | `X-Request-Id` | | ใช้ทั้งขาเข้าและขาออก |
| คำขอที่ไม่เข้าระบบต่อนาทีต่อที่อยู่ | `api.anonymous_requests_per_minute` | 60 | 20–600 | health ไม่ถูกนับ |
| origin อื่นที่เรียก API ได้ | `api.cors_origins` | ว่าง | รายการ `https://host` หรือ `https://host:port` | ว่างคือเรียกได้จาก origin เดียวกันเท่านั้น ห้าม `*` |
| ขนาดคำขอสูงสุด | `api.body_max_mb` | 12 MB | 1–100 | proxy และ API ใช้ค่าเดียวกัน ไฟล์ใหญ่สุดที่อัปโหลดได้ต้องเล็กกว่าพอให้ส่วนหัวของฟอร์มพอดี |
| รอฐานข้อมูลตอน start | `api.db_wait_seconds` | 60 วินาที | 10–300 | เกินแล้ว API จบด้วย error |
| หน่วยความจำของ proxy | `api.memory_proxy_mb` | 64 MB | 32–256 | |
| หน่วยความจำของ API | `api.memory_api_mb` | 768 MB | 512–2048 | รวมงานเบื้องหลังที่รันใน process เดียวกัน |
| หน่วยความจำของเว็บที่ render ฝั่ง server | `api.memory_web_mb` | 512 MB | 256–1024 | ต่อ container ของเว็บ เมื่อเว็บแยก container |
| หน่วยความจำของฐานข้อมูล | `api.memory_db_mb` | 1024 MB | 512–8192 | |
| ที่เก็บไฟล์ contract | `api.contract_path` | `contracts/openapi.json` | path ใน repo | client ของเว็บสร้างจากไฟล์นี้ |
