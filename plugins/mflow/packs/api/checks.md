# สิ่งที่ลองตอนทดสอบใช้งาน

1. เครื่องใหม่: copy `.env.example` เป็น `.env` แล้วรัน `docker compose up` คำสั่งเดียว → ทุกเว็บเปิดได้ผ่าน proxy และ `/api/v1/health/ready` ตอบ 200
2. ส่งฟอร์มที่ผิดสองช่องพร้อมกัน → ได้ 400 `VALIDATION_FAILED` ที่มีทั้งสองช่องในคำตอบเดียว จอแสดงข้อความใต้ทั้งสองช่อง และไม่มีอะไรถูกบันทึก
3. สองคนเปิดระเบียนเดียวกัน คนแรกบันทึก แล้วคนที่สองบันทึก → คนที่สองได้ 409 `<RESOURCE>_CHANGED` สิ่งที่พิมพ์ยังอยู่ และมีปุ่มโหลดใหม่ ค่าของคนแรกยังอยู่
4. ใส่ id ของระเบียนนอกขอบเขตใน address แล้วใส่ id ที่ไม่มีอยู่ → ทั้งสองได้ 404 `NOT_FOUND` หน้าตาเหมือนกัน
5. เปิดรายการที่มีมากกว่าหนึ่งหน้า เรียงด้วยคอลัมน์ที่ค่าซ้ำกันเยอะ แล้วกดดูทีละหน้า → ไม่มีแถวซ้ำหรือหายระหว่างหน้า และขอ `pageSize` เกินค่าสูงสุดได้ 400
6. บันทึกเอกสารตอน 23:30 ตามเขตเวลาของระบบ แล้วกรองด้วยวันนั้น → เอกสารอยู่ในผล และ JSON ของคำตอบเป็นเวลา UTC ที่ลงท้าย `Z`
7. ทำให้ endpoint หนึ่งพัง → จอแสดงข้อความกลางๆ พร้อม request id และหา stack trace ใน log ได้ด้วย request id นั้น โดยคำตอบไม่มี stack trace
8. เรียก API พร้อม header `Authorization` หรือเปลี่ยนรหัสผ่าน แล้วค้น log → ไม่มีค่าของ header รหัสผ่าน หรือโทเค็นใน log
9. ยิงคำขอลืมรหัสผ่านจากที่อยู่เดียวเกินค่าที่ตั้งในหนึ่งนาที → ได้ 429 พร้อม `Retry-After` ส่วนผู้ใช้ที่เข้าระบบแล้วยังทำงานได้ตามปกติ
10. หยุดฐานข้อมูลระหว่างที่ระบบรันอยู่ → `/health` ยังตอบ 200 แต่ `/health/ready` ตอบ 503 `DATABASE_UNAVAILABLE` โดยไม่บอกชื่อเครื่องหรือ connection string
11. start API บน Production โดยเปิดโหมด prototype หรือใช้รหัสผ่านที่ยังเท่ากับค่าตัวอย่าง → API ไม่ start และข้อความบอกชื่อค่าที่ผิด ไม่บอกค่า
12. เปิด `/api/v1/docs` บน Staging แล้วบน Production → Staging เห็นเอกสาร Production ได้ 404
13. ส่งไฟล์ที่ใหญ่กว่าขนาดคำขอสูงสุดผ่าน proxy → ได้ 413 และจอบอกว่าไฟล์ใหญ่เกิน
14. (test) เพิ่ม endpoint โดยไม่สร้างไฟล์ contract ใหม่ → test เทียบ contract ล้มและบอก path ที่ต่าง
15. (test) เขียนโค้ดธุรกิจที่อ่านเวลาของเครื่องเอง หรือ response model ที่มีฟิลด์ชื่อ `PasswordHash` → architecture test ล้มและบอกตำแหน่ง
16. (test) ทำให้ migration ล้มตอน start → process จบด้วย error และไม่ตอบคำขอใด
