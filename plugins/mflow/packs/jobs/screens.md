# jobs screens

| หน้าจอ | ทำอะไร | ใครใช้ | หมายเหตุ |
|---|---|---|---|
| งานเบื้องหลัง (`Jobs · งานเบื้องหลัง`) | แถบตัวเลข (ทั้งหมด ปกติ กำลังรัน ล้ม ปิดอยู่) แถบเตือนเมื่อมีงานล้มติดกัน และตารางงาน: ชื่อ ชนิด รอบเวลาเป็นข้อความ สถานะรอบล่าสุด เริ่ม จบ ระยะเวลา จำนวนรายการ error รอบถัดไป ปุ่มสั่งรัน แก้รอบ ดูประวัติ | ผู้ถือ `{job_view_key}` | ปุ่มสั่งรันและแก้รอบแสดงเฉพาะผู้ถือ `{job_manage_key}` งานปิดอยู่ขึ้น `Disabled · ปิดการใช้งาน` และไม่มีรอบถัดไป งานเลยเวลาขึ้น `Late · เลยเวลา` ตารางรีเฟรชเองระหว่างมีงานกำลังรัน เมนูไม่มีเมื่อไม่มีสิทธิ์ |
| ประวัติรอบของงาน | รายการรอบ ใหม่ก่อน แบ่งหน้า: สถานะ ผู้เริ่ม เริ่ม จบ จำนวนรายการ error และปุ่มลองใหม่ของงานครั้งเดียวที่เป็น Failed | ผู้ถือ `{job_view_key}` | ปุ่มลองใหม่เฉพาะผู้ถือ `{job_manage_key}` ไม่มี stack trace บนจอ |
| กล่องสั่งรัน | ชื่องาน ผลของงาน ข้อความว่างานรันทันทีและบันทึกชื่อคนสั่ง ปุ่มสั่งรันและยกเลิก | ผู้ถือ `{job_manage_key}` | งานกำลังรันกดไม่ได้ ถ้าเริ่มระหว่างเปิดกล่องขึ้นข้อความ `The job is already running · งานนี้กำลังทำงานอยู่` |
| กล่องแก้รอบเวลา | สวิตช์เปิดปิด รูปแบบ (ทุก N นาที ทุกวัน ช่วงวันของเดือน) ช่องของรูปแบบที่เลือก คำเตือนผลของการปิดงานนั้น | ผู้ถือ `{job_manage_key}` | งานที่รอบตายตัวแสดงแค่สวิตช์ รูปแบบอื่นในฐานข้อมูลแสดง `Other: <cron>` และยังเปิดปิดได้ ข้อผิดแสดงข้างช่องที่ผิด |
| ค่าการเตือนบนหน้าตั้งค่าระบบ | จำนวนรอบที่ล้มก่อนเตือน รายชื่ออีเมลรับการเตือน | ผู้ดูแลระบบ | หน้าตั้งค่าเป็นของแพ็ก settings ถ้าไม่มีอยู่ใน config |
