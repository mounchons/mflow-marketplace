# หน้าจอของแพ็ก users

| หน้าจอ | พอร์ทัล | ใช้ทำอะไร | ใครเปิดได้ |
|---|---|---|---|
| Manage Users (รายการ) | `{portal}` | ดูบัญชีพนักงาน ค้นหา กรองตามกลุ่มและสถานะ แบ่งหน้าที่ server ปุ่มสร้าง | ผู้ถือสิทธิ์ View (seed: SuperAdmin) |
| ฟอร์มบัญชีพนักงาน | `{portal}` | สร้างหรือแก้ username ชื่อ อีเมล กลุ่ม สถานะ, ประวัติจาก Activity Log, ปุ่ม Reset password และ Delete | ผู้ถือสิทธิ์ View และสิทธิ์ของแต่ละปุ่ม |
| กล่องบัญชีขององค์กร (ในหน้ารายละเอียดของ `{org}`) | `{portal}` | ดูบัญชีขององค์กร เพิ่ม แก้ เชิญใหม่ ตั้งบัญชีหลัก | พนักงานที่ถือสิทธิ์และมีองค์กรนั้นในขอบเขต |
| บัญชีผู้ใช้ขององค์กร | `{org_portal}` | ผู้ดูแลขององค์กรเพิ่ม แก้ เชิญใหม่ ตั้งบัญชีหลัก เฉพาะองค์กรตัวเอง | role ผู้ดูแลขององค์กร |
| Profile | `{org_portal}` | ข้อมูลองค์กร (อ่านอย่างเดียว) แก้ชื่อ เบอร์ อีเมลของตัวเอง เปลี่ยนรหัสผ่าน | ทุกบัญชีขององค์กร |

ข้อความบนจอ: กล่องยืนยันของ Reset password บอกว่าจะส่งลิงก์ทางอีเมล ไม่ใช่รหัสชั่วคราว, ปุ่ม Delete ใช้แบบที่ย้อนไม่ได้, ฟอร์มที่ยังไม่บันทึกถามก่อนออก, ช่องรหัสผ่านปัจจุบันบน Profile โผล่เมื่ออีเมลต่างจากที่บันทึกไว้เท่านั้น
