# import-export: ค่าเริ่มต้น

เฉพาะค่าที่กำกับ `ตั้งบนจอ` อยู่บนหน้าตั้งค่าระบบ (แท็บ Import / Export ของแพ็ก settings) ถ้าโปรเจกต์ไม่มีหน้าตั้งค่า ค่าเหล่านี้อยู่ใน config ค่าอื่นอยู่ในโค้ดหรือ config ตอน deploy ค่าที่เอกสารลูกค้ากำหนดใช้แทนค่าเริ่มต้น

| ค่า | key | เริ่มต้น | ช่วง | หมายเหตุ |
|---|---|---|---|---|
| ขนาดไฟล์นำเข้าสูงสุด (MB) | `import-export.import_max_file_mb` | 10 | 1–100 | ตั้งบนจอ ไม่เกินเพดานคำขอของ server (`upload.request_limit_mb`) |
| แถวสูงสุดต่อไฟล์นำเข้า | `import-export.import_max_rows` | 10000 | 100–50000 | ตั้งบนจอ นับแถวใต้หัวตาราง เกินเพดานช่วงต้องเปลี่ยนตัวอ่านเป็นแบบ stream |
| คอลัมน์สูงสุดต่อชีท | `import-export.import_max_columns` | 50 | 10–200 | นับทุกชีทในไฟล์ |
| ชีทสูงสุดต่อไฟล์ | `import-export.import_max_sheets` | 20 | 1–50 | นับชีทที่ซ่อนด้วย |
| ตัวอักษรสูงสุดต่อเซลล์ | `import-export.import_max_cell_chars` | 4000 | 255–32767 | Excel รับได้ 32,767 ตัวอักษร |
| ขนาดรวมหลังแตกไฟล์ (MB) | `import-export.import_max_unpacked_mb` | 60 | 20–500 | ตรวจก่อนอ่านเซลล์แรก กันไฟล์ zip ที่แตกแล้วใหญ่เกินจริง |
| ไฟล์ตั้งแต่ขนาดนี้ตรวจเป็นงานเบื้องหลัง (MB) | `import-export.import_job_file_mb` | 2 | 1–100 | IMPEX-D15 |
| แถวตั้งแต่จำนวนนี้บันทึกเป็นงานเบื้องหลัง | `import-export.import_job_rows` | 2000 | 100–50000 | IMPEX-D15 |
| ชุดที่กำลังทำค้างได้นานสุด (นาที) | `import-export.import_running_timeout_minutes` | 60 | 10–1440 | เกินแล้วชุดนั้นเป็น `Failed` |
| รูปวันที่ในเซลล์ข้อความ | `import-export.date_text_format` | `d/M/yyyy` | `d/M/yyyy` หรือ `yyyy-M-d` | ปีสี่หลักเท่านั้น วันและเดือนหลักเดียวได้ |
| ปีตั้งแต่เท่านี้ถือเป็น พ.ศ. | `import-export.buddhist_year_from` | 2400 | 2200–2600 | ลบ 543 ก่อนตรวจว่าเป็นวันที่จริง IMPEX-D11 |
| แถวสูงสุดที่ส่งออกในคำขอเดียว | `import-export.export_sync_max_rows` | 5000 | 100–20000 | เกินแล้วเป็นงานเบื้องหลัง |
| แถวสูงสุดต่อไฟล์ส่งออก | `import-export.export_max_rows` | 50000 | 1000–200000 | ตั้งบนจอ เกินแล้วปฏิเสธ `EXPORT_TOO_LARGE` เพดานช่วงเกินกว่านี้ต้องเปลี่ยนตัวเขียนเป็นแบบ stream |
| อายุลิงก์ไฟล์ส่งออก (ชั่วโมง) | `import-export.export_link_hours` | 24 | 1–168 | เกินแล้วดาวน์โหลดไม่ได้ และงานล้างลบไฟล์ |
| รูปวันที่ในไฟล์ส่งออก | `import-export.export_date_format` | `dd/mm/yyyy` | รูปวันที่ของ Excel | ปี ค.ศ. ตามค่าเริ่มต้น เซลล์เป็นเซลล์วันที่จริง |
