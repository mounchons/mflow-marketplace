# auth: ทดสอบใช้งาน

1. ที่ `/login` ใส่อีเมลที่มีบัญชีกับรหัสผิด แล้วใส่อีเมลที่ไม่มีบัญชี ข้อความต้องเหมือนกันทุกตัวอักษร
2. ใช้บัญชี Disabled ใส่รหัสถูก ต้องได้ข้อความให้ติดต่อผู้ดูแล โดยไม่มีคำว่า Disabled
3. ใส่รหัสผิดครบจำนวนที่ล็อก แล้วใส่รหัสถูก ต้องได้ข้อความล็อกที่บอกจำนวนนาที และเข้าได้หลังครบเวลา อีเมลที่ไม่มีบัญชีก็ต้องถูกล็อกแบบเดียวกัน
4. เปิดหน้าลึก เช่น `/orders` ตอนยังไม่เข้าระบบ เข้าแล้วต้องกลับมาที่หน้านั้น และ `next` ที่ชี้ออกไปเว็บอื่นต้องพาไปหน้าแรกของพอร์ทัล
5. เข้าระบบสองเครื่อง ให้ผู้ดูแลปิดบัญชี คำขอถัดไปของทั้งสองเครื่องต้องกลับไปหน้าเข้าระบบ ส่วนการแก้ชื่อที่แสดงต้องไม่ตัดเซสชัน
6. ตั้งรหัสใหม่ที่ผิดหลายข้อพร้อมกัน เช่น `abc` ข้อความต้องบอกทุกข้อที่ผิดพร้อมตัวเลข และรหัสที่ซ้ำรหัสล่าสุดต้องถูกปฏิเสธ
7. กดลืมรหัสด้วยอีเมลที่มีและไม่มีบัญชี ข้อความต้องเหมือนกัน เปิดลิงก์จาก mailbox ของ prototype ตั้งรหัสได้ครั้งเดียว ลิงก์เดิมเปิดซ้ำต้องบอกว่าหมดอายุ
8. บัญชีใหม่ (Invited) เข้าครั้งแรกต้องเห็นแค่หน้าเข้าครั้งแรก เรียก API อื่นตรงๆ ต้องได้ `FIRST_LOGIN_REQUIRED` บันทึกแล้วสถานะเป็น Active
9. เปิดสวิตช์ OTP ของพอร์ทัลหนึ่ง เข้าระบบแล้วต้องได้หน้ารหัสยืนยันที่แสดงอีเมลแบบปิดบางส่วน ใส่รหัสผิดหนึ่งครั้งแล้วใส่รหัสถูกต้องเข้าได้ อีกพอร์ทัลที่สวิตช์ปิดต้องไม่ถามรหัส
10. ผ่าน OTP แล้วออกและเข้าใหม่บน browser เดิมต้องไม่ถามรหัส เปลี่ยน browser หรือเปลี่ยนรหัสผ่านแล้วต้องถามรหัสอีกครั้ง
11. ดู Activity Log หลังทดสอบข้อ 1–10: มีรายการของบัญชีจริงทุกครั้ง ไม่มีรายการของอีเมลที่ไม่มีบัญชี และไม่มีรหัสผ่าน โทเค็น หรือรหัส OTP ในรายการใด
12. บน prototype เข้าระบบแล้วสลับผู้ใช้เป็นบัญชีอื่น ต้องเห็นเมนูของบัญชีนั้นโดยไม่ถามรหัส และหน้าเปิดใหม่ที่ยังไม่เข้าระบบต้องไม่สลับให้อัตโนมัติ
