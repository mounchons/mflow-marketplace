# import-export screens

| หน้าจอ | ทำอะไร | ใครใช้ | หมายเหตุ |
|---|---|---|---|
| หน้านำเข้า `{import_target}` | ช่องเลือกไฟล์พร้อมขีดจำกัดที่ใช้อยู่ ปุ่ม Download template ข้อความว่ายังไม่มีอะไรถูกบันทึกก่อนยืนยัน ผลตรวจ (จำนวนผ่าน ไม่ผ่าน จะสร้าง จะแก้) คำเตือนเมื่อมีแถวที่จะไม่ถูกนำเข้า รายการแถวผิดแบบแบ่งหน้าพร้อมเลขแถว คอลัมน์ เหตุผล ปุ่ม Download error report, Cancel และ Confirm | ผู้ถือ `{import_key}` | Confirm เปิดเมื่อยืนยันได้เท่านั้น กล่องยืนยันบอกจำนวนจะสร้าง จะแก้ และแถวที่จะไม่ถูกนำเข้า ไฟล์ที่ถูกปฏิเสธทั้งไฟล์แสดงข้อความที่ช่องเลือกไฟล์ งานเบื้องหลังแสดงจำนวนแถวที่ทำแล้วจากทั้งหมด และปิดหน้าแล้วกลับมาดูได้ |
| ปุ่ม Export บนรายการ `{list}` | สร้างไฟล์จากตัวกรองและการเรียงที่เห็นอยู่ ไฟล์เล็กดาวน์โหลดทันที ไฟล์ใหญ่บอกว่ากำลังทำและจะแจ้งเมื่อเสร็จ เกินเพดานบอกจำนวนแถวและให้แคบตัวกรอง | ผู้ถือ `{export_key}` | มีเฉพาะ `{list}` ที่โปรเจกต์ตกลง ปุ่มปิดระหว่างทำ |
| รายการไฟล์ส่งออกของฉัน | ไฟล์ที่ขอไว้ สถานะ จำนวนแถว เวลาหมดอายุ ปุ่ม Download เมื่อพร้อม | ผู้ขอไฟล์ | เห็นเฉพาะไฟล์ของตัวเอง ไม่แสดงไฟล์ที่หมดอายุ |
| แท็บ Import / Export บนหน้าตั้งค่าระบบ | ขนาดไฟล์นำเข้าสูงสุด แถวสูงสุดต่อไฟล์นำเข้า แถวสูงสุดต่อไฟล์ส่งออก | ผู้ดูแลระบบ | หน้าตั้งค่าเป็นของแพ็ก settings ถ้าไม่มี ค่าเหล่านี้อยู่ใน config |
