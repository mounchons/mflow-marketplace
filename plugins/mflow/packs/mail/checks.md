# mail checks

สิ่งที่ลองตอนทดสอบใช้งาน แต่ละข้อเป็น test หรือ acceptance criterion ได้

1. สวิตช์ส่งปิด: ขอลิงก์ลืมรหัสผ่าน แล้วเปิด mailbox โดยไม่เข้าระบบ ต้องเห็นอีเมลพร้อมลิงก์ และไม่มีการต่อ SMTP
2. เปิดสวิตช์ส่งหลังมีอีเมลค้างในคิว: อีเมลที่เข้าคิวก่อนเปิดต้องคงเป็น Queued และไม่ถูกส่ง ส่วนอีเมลใหม่ถูกส่ง
3. allow-list เป็น `@example.com`: อีเมลถึง `tester@example.org` ต้องเป็น Skipped "Not on the allow-list" และ mailbox ยังแสดงรหัสผ่านเริ่มต้นของอีเมลนั้น
4. ทำ allow-list ที่มีค่าให้ว่างแล้วกดบันทึก ต้องถูกถามยืนยันก่อน และ Activity Log มีค่าเก่าและใหม่
5. ตั้งจำนวนต่อชั่วโมงเป็น 2 แล้วทำให้เกิดอีเมล 3 ฉบับ: 2 ฉบับถูกส่ง อีก 1 ฉบับรอรอบถัดไป ไม่หายและไม่ถูกข้าม
6. ปิด mail server ระหว่างส่ง: อีเมลถูกลองใหม่ตามรอบ ครบจำนวนครั้งแล้วเป็น Failed และ `mail_log` มีแถว Failed ทุกครั้ง
7. ส่งรหัสเข้าระบบ แล้วค้น `mail_log`: ต้องไม่มีตัวรหัส รหัสผ่านเริ่มต้น หรือโทเค็นลิงก์ในแถวใด
8. ลบแท็กลิงก์ออกจากเทมเพลตลิงก์ตั้งรหัสผ่าน: ปุ่มบันทึกต้องปิดพร้อมข้อความที่ระบุแท็ก ส่วนสำเนาของเทมเพลตนั้นบันทึกได้
9. ปิดเทมเพลตที่ผูกกับแถวหนึ่ง: ต้องมีหน้ายืนยันที่ระบุแถว และหลังยืนยัน แถวนั้นไม่มีเทมเพลตและขั้นที่เปิดอยู่บันทึกไม่ได้จนกว่าจะเลือกใหม่
10. ปิดขั้นหนึ่งแล้วทำให้เกิดเหตุการณ์ของขั้นนั้น: ไม่มีอีเมลเข้าคิว และเปิดขั้นภายหลังก็ไม่ส่งย้อนหลัง
11. ลบสำเนาที่ยังผูกกับแถวอยู่: ต้องถูกปฏิเสธพร้อมชื่อแถว
12. สองคนเปิดจอผูกพร้อมกันแล้วบันทึกทั้งคู่: คนที่สองได้ข้อความว่าข้อมูลเปลี่ยนแล้ว และค่าของคนแรกคงอยู่
13. อีเมลถึง `{org}` ที่มีสามบัญชี role ต่างกัน: เฉพาะบัญชีที่ role เปิดส่วนของอีเมลนั้นได้รับ คนละข้อความ บัญชีที่ยัง Invited ก็ได้รับ
14. ปิดโหมด prototype: เปิดที่อยู่ของ mailbox แล้วต้องไม่เห็นอีเมลใด
15. แท็บอีเมลในหน้าตั้งค่า: ใส่ค่า SMTP แล้วกดส่งทดสอบไปอีเมลของตัวเอง ต้องได้ผลภายใน 30 วินาที ใส่รหัสผิดแล้วทดสอบอีกครั้ง ต้องเห็นคำตอบของ server โดยไม่มีรหัสหรือชื่อผู้ใช้ในข้อความ เปิดหน้าใหม่แล้วช่องรหัสต้องว่าง (แสดงว่ามีค่า) ไม่ใช่ตัวรหัส
16. ล้าง SMTP host บนจอขณะสวิตช์ส่งเปิด แล้วขอลิงก์ลืมรหัส: อีเมลต้องค้างที่ Queued โดยไม่นับการลอง และหน้าตั้งค่าต้องบอกว่า SMTP ยังไม่ได้ตั้ง ใส่ host กลับแล้วอีเมลต้องออกในรอบถัดไปโดยไม่ restart
