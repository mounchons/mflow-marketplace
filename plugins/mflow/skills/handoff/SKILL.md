The Stop hook asks for a short STATUS entry during work. This is the thorough version, for the end of a day, before a break of several days, or before another tool picks the work up.

1. **Collect facts, not recollection:** `git status`, `git log --oneline` since the last STATUS entry, `openspec list --json`, `backlog task list -s "In Progress" --plain`, the result of the test command from AGENTS.md.
2. **Move what is no longer current, first, while the file is still large to edit:** run `node "${CLAUDE_PLUGIN_ROOT}/scripts/status-trim.mjs" plan`. It lists the blocks of `## Now` (a line at column 0 that starts with `- `, with the lines under it), each with its first line and its `Next` and `Blocked on` lines, the sections that stand between `## Now` and `## Log` (such as `## Previous session context`), and the log entries. Decide how many of the first blocks are the current state: usually 1 when each session wrote one block, all of them for a Now of single lines such as `- Focus:` / `- Next step:` / `- Blocked on:`. Note the `Next` and `Blocked on` items of the other blocks that are not done yet. Check the number against the list before moving; STATUS.md and `docs/status-log.md` are in git, so a wrong number is undone with `git checkout -- STATUS.md docs/status-log.md`. Then run `status-trim.mjs move --keep <that number> --log 9`: it moves the other blocks and those sections to the end of `docs/status-log.md` under `## Now blocks moved on <date>`, and the log entries past the newest 9 to its top, newest first (the entry of step 4 makes 10), all word for word. Never move them by hand, and never shorten, merge or summarise them.
3. **Rewrite `## Now`** in STATUS.md so it holds only the current state: focus (change name / task IDs), exact next step (the literal command or file to open), blocked on (who, what, since when), state of the working tree (clean / uncommitted and why), and `Still open:` with one line for each item of step 2 that is not done yet (what, and the date of its block in `docs/status-log.md`). Only items that live nowhere else get a line: a test or review that a change still owes is in `docs/reviews/pending.md`, and work that is a Backlog task is in Backlog, so neither needs one. Replace the current block's text instead of adding a new block above it, and keep `## Now` under about 60 lines.
4. **Add one log entry:** Did / Decided (with Backlog decision or task IDs) / Learned (gotchas worth adding to AGENTS.md if they recur) / Next. If STATUS.md still has the old comment that says to fold older entries into one summary line, replace it with the template's comment.
5. **With `--for <tool>`:** also follow `${CLAUDE_PLUGIN_ROOT}/skills/delegate/SKILL.md` for the next task in mode `code`, so the other tool starts from a brief instead of the chat history. Files opened with Read are not substituted: where that file writes the plugin-root variable (CLAUDE_PLUGIN_ROOT), use `${CLAUDE_PLUGIN_ROOT}`.

Done when: someone who has seen none of today's conversation could continue from STATUS.md alone, and STATUS.md holds only the current `## Now` and the newest 10 log entries.
