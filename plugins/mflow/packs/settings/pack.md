แพ็กนี้เป็นเจ้าของหน้าตั้งค่าระบบ และกติกาที่ใช้กับทุกค่าบนหน้านั้น: ชนิดของค่า ที่เก็บ ความลับ การตรวจ การยืนยัน การบันทึกทีละแท็บ Activity Log และเวลาที่ค่าใหม่มีผล ค่าแต่ละตัวเป็นของแพ็กที่ใช้มัน และอยู่ใน params.md ของแพ็กนั้น (`auth.*`, `mail.*`, `upload.*` …) แพ็กนี้จึงไม่มีรายชื่อค่าของตัวเอง catalog ของโปรเจกต์คือทุกค่าใน params.md ของแพ็กที่เลือก บวกค่าของโปรเจกต์เอง แท็บละหนึ่งแพ็กหรือหนึ่งเรื่อง

## ครอบคลุม

- catalog ในโค้ด: คีย์ แท็บ ชนิด หน่วย ช่วง ค่าเริ่มต้น ชื่อ และคำอธิบายสองบรรทัดของทุกค่า ฐานข้อมูลเก็บแค่ค่า
- ชนิดของค่า: จำนวนเต็มพร้อมช่วงและหน่วย เปิด/ปิด ข้อความ list ตัวเลือกเดียว ตัวเลือกหลายข้อ และความลับ
- ค่าไหนอยู่ใน env ค่าไหนอยู่บนจอ ค่า env เดิมเป็นค่าตั้งต้นครั้งแรกเท่านั้น และ env ฉุกเฉินที่แพ็กเจ้าของกำหนด
- ความลับ: เข้ารหัสด้วยกุญแจจาก env ไม่ส่งกลับไป browser แสดงแค่ว่าตั้งแล้วหรือยัง ช่องว่างคือคงค่าเดิม ล้างด้วยปุ่มของมัน ไม่ลง log การเปลี่ยนกุญแจ
- การตรวจทั้งแท็บพร้อมทุกข้อผิด ค่าความปลอดภัยที่ห้ามหลวมกว่าขอบ และการยืนยันการเปลี่ยนที่อันตราย
- บันทึกทีละแท็บใน transaction เดียว รุ่นต่อค่า (409) Cancel และการคืนค่าเริ่มต้น
- Activity Log หนึ่งรายการต่อการบันทึก ค่าเก่าและค่าใหม่ต่อคีย์ ความลับไม่มีค่า
- ค่าใหม่มีผลโดยไม่ restart งานที่เริ่มแล้วใช้ค่าตอนเริ่ม ค่าต่อ `{portal}` และค่าที่อยู่นอกช่วงของรุ่นใหม่
- หน้าตั้งค่าระบบ: แท็บ ช่องตามชนิด คำอธิบาย ปุ่ม Save Cancel Default Reset tab Clear กล่องยืนยัน และแถบแจ้งเมื่อมีคนแก้ก่อน

## ไม่รวม

- ค่าแต่ละตัว ช่วง ค่าเริ่มต้น และผลเฉพาะของการเปลี่ยน (เช่นคำนวณวันหมดอายุรหัสใหม่ทุกบัญชี): แพ็กเจ้าของค่า
- ปุ่มเฉพาะของแท็บ เช่นส่งอีเมลทดสอบ: แพ็กเจ้าของค่า (อีเมลอยู่ในแพ็ก `mail`) แพ็กนี้แค่วางปุ่มไว้ในแท็บ
- ช่องสิทธิ์ View และ Manage และกลุ่มที่ถือ: แพ็ก `permission` แพ็กนี้ใช้แค่ชื่อคีย์ของโปรเจกต์
- ข้อมูลหลักที่เป็นรายการ (สาขา หน่วยนับ ประเภทเอกสาร) และเนื้อหายาวหรือ HTML ของหน้าสาธารณะ: มีตารางและหน้าจอของตัวเอง ไม่ใช่ค่าตั้ง
- ค่าที่มีหน้าจอของตัวเองแล้ว เช่นเทมเพลตอีเมลและตารางเวลางาน
- การ export หรือคัดลอกค่าระหว่างเครื่อง และหน้าประวัติแยก (ดู SET-D23)
- ภาษาของป้ายบนจอ: ตามกติกาของโปรเจกต์ ค่าเริ่มต้นเป็นคู่ `English · ไทย` โปรเจกต์ภาษาเดียวใช้ครึ่งเดียว

## คำกำกับใน params.md ของแพ็กเจ้าของค่า

แพ็กเจ้าของค่าเขียนคำเหล่านี้ในช่อง หมายเหตุ ของ params.md เป็นคำแยก (หลายคำได้) แพ็กนี้อ่านคำกำกับแล้วใช้กติกาเดียวกันกับทุกค่า ค่าที่ไม่มีคำกำกับเป็นค่าธรรมดา ค่าเดียวทั้งระบบ

| คำกำกับ | ความหมาย | ข้อ |
|---|---|---|
| `ไม่ขึ้นจอ` | ค่าอยู่ในโค้ดหรือ config ตอน deploy ไม่อยู่ใน catalog | SET-D02 |
| `ตั้งบนจอ` หรือ `บนจอ` | เมื่อย่อหน้าแรกของ params.md บอกว่าเฉพาะค่าที่กำกับอยู่บนจอ ค่าที่ไม่กำกับอยู่ในโค้ด | SET-D02 |
| `ต่อพอร์ทัล` | มีค่าแยกของแต่ละ `{portal}` | SET-D20 |
| `ค่าความลับ` | ค่าลับ เช่นรหัสผ่านของระบบภายนอก อยู่บนจอเสมอ | SET-D08, SET-D09 |
| `ห้ามต่ำกว่า <ค่า>`, `ห้ามเกิน <ค่า>`, `ห้ามปิด` | ค่าความปลอดภัย: ขอบที่ห้ามหลวมกว่า ไม่เขียนค่าคือขอบเป็นค่าเริ่มต้น ประโยครวมในย่อหน้าแรกที่ไม่บอกทาง ใช้ปลายช่วงเป็นขอบ | SET-D14 |
| `ทำให้ว่างต้องยืนยัน`, `ปิดต้องยืนยัน`, `เปิดต้องยืนยัน` | การเปลี่ยนที่ต้องยืนยันก่อนบันทึก | SET-D15 |
| `env ฉุกเฉิน <ชื่อ>` | env ที่บังคับค่าที่แพ็กเจ้าของกำหนดโดยไม่แก้ค่าที่เก็บ | SET-D22 |
| `แท็บ <ชื่อ>` | แบ่งค่าของแพ็กเดียวเป็นหลายแท็บ | SET-D01 |

## คำของโปรเจกต์

| คำ | ความหมาย | ตัวอย่าง |
|---|---|---|
| `{portal}` | พอร์ทัลหรือเว็บที่มีค่าแยกกันเมื่อค่านั้นกำกับ `ต่อพอร์ทัล` | พอร์ทัลพนักงาน, พอร์ทัลคู่ค้า |
| `{settings_view_key}` | สิทธิ์ดูหน้าตั้งค่า | `SETTINGS.View` |
| `{settings_manage_key}` | สิทธิ์บันทึกค่าบนหน้าตั้งค่า | `SETTINGS.Manage` |
| `{superadmin}` | กลุ่มผู้ดูแลสูงสุดใน seed | SuperAdmin |
| `{api_prefix}` | ส่วนหน้าของ route API | `/api/v1` |
